Why this matters · ليه ده مهم

English

You have spent forty lessons on what ERP is. This one asks what to do about it, and it starts with an uncomfortable fact: the three numbers that matter most for your decision do not exist in any source we could read. Those are the live job count, Odoo pay in Egypt, and how hard it is to return to product engineering afterwards. Everything else is either a proxy or an inference, and this lesson labels which is which.

That makes it a lesson about judgement as much as about careers. Deciding with incomplete data, grading a source, refusing to print a number that a sample can't support, and writing down what would change your mind: these are the same skills you use on a design doc or an incident review. Every market figure below was read on 9 November 2026 by the research behind this section. Nothing was re-fetched from a job board while writing this page.

English

What the 8 MENA postings show. Six of the eight read in full were already expired, and the sample is biased towards what could be reached, so treat this as last year's picture: Python 8/8, PostgreSQL 8/8, XML/QWeb 7/8, JavaScript 6/8, integration 5/8, accounting 3/8, OWL as a requirement 1/8, certification preferred 1/8, Arabic as an advantage 1/8, ZATCA or ETA 0/8. One Cairo posting outside that sample, K-Line, does list ETA work and calls knowledge of the specs "a significant advantage". The report's inference is that e-invoicing reaches developers as project work more than as a hiring keyword.

E-invoicing is the driver with real dates (details in 31, 32 and 33). UAE: Ministerial Decision 66 of 2026 requires revenue of AED 50,000,000 or more to appoint an ASP by 30 October 2026 and go live by 1 January 2027. KPMG reports go-live on 1 July 2027 for smaller businesses and 1 October 2027 for government entities. One secondary source gives 31 March 2027 for these groups instead. In the Ministry's release and KPMG's table that date is the deadline for appointing an ASP, so the two may be one date read differently: read the Ministry's own text before planning on any of them. Saudi: Wave 25 covers VAT-taxable revenue above SAR 187,500 in any of 2022–2025, by 1 February 2027. The threshold has halved wave after wave, so the report infers this wave reaches small firms that buy packaged compliance rather than hire developers. Egypt: the e-invoice mandate was complete by 15 December 2022; e-receipt is still rolling out in phases according to a Sovos snippet, while Avalara presents it as one step, so the sources differ. The inference: Egypt is maintenance work.

Remote wasn't measured. Upwork refused access. Of the 8 postings, 3 were hybrid, 1 remote freelance and 4 didn't say, and two carried residency terms: Egyptians resident in Egypt at Archer, a valid Saudi residency at Al-Ghomlas. The most plausible remote route is a partner already serving the Gulf (Plementus is Gold in both Egypt and the UAE), but no posting proves it. On-site in Saudi Arabia is also narrowed by localisation: a 2020 HRSD decision covers IT professions, including programming, in firms with 5 or more such staff; the 25% rate comes from secondary sources and its 2026 status is unconfirmed.

One general signal: Cooper Fitch found total hiring in Q1 2026 up 1% in the UAE and 0.5% in Saudi Arabia, and software hiring in the Gulf up 5%, which it attributed to ERP upgrades, workflow automation and custom applications. The war that began on 28 February slowed March. That's overall hiring, not Odoo.

function reconcile(ledger: LedgerSale[], erp: ErpInvoice[]): Finding[] {
  const findings: Finding[] = [];
  const live = erp.filter((i) => i.state !== "cancel");
  const byRef = Map.groupBy(live, (i) => i.ref);
  const known = new Set(ledger.map((s) => s.orderId));

  for (const sale of ledger) {
    const invoices = byRef.get(sale.orderId) ?? [];
    if (invoices.length === 0) {
      findings.push({ kind: "missing-in-erp", orderId: sale.orderId, amountMinor: sale.amountMinor });
      continue;
    }
    if (invoices.length > 1) {
      findings.push({ kind: "duplicate-in-erp", orderId: sale.orderId, invoiceIds: invoices.map((i) => i.id) });
      continue;
    }
    const [invoice] = invoices as [ErpInvoice];
    if (invoice.state !== "posted") {
      findings.push({ kind: "not-posted", orderId: sale.orderId, invoiceId: invoice.id, state: invoice.state });
    }
    if (invoice.amountMinor !== sale.amountMinor) {
      findings.push({ kind: "amount-mismatch", orderId: sale.orderId, diffMinor: invoice.amountMinor - sale.amountMinor });
    }
  }
  for (const invoice of live) {
    if (!known.has(invoice.ref)) findings.push({ kind: "orphan-in-erp", invoiceId: invoice.id, ref: invoice.ref });
  }
  return findings;
}

export function parseCsv(text: string): string[][] {
  const rows: string[][] = [];
  let row: string[] = [];
  let cell = "";
  let quoted = false;
  const src = text.replace(/^\uFEFF/, "");
  for (let i = 0; i < src.length; i++) {
    const ch = src[i];
    if (quoted) {
      if (ch === '"' && src[i + 1] === '"') { cell += '"'; i++; }
      else if (ch === '"') quoted = false;
      else cell += ch;
    } else if (ch === '"') quoted = true;
    else if (ch === ",") { row.push(cell); cell = ""; }
    else if (ch === "\n") { row.push(cell.replace(/\r$/, "")); rows.push(row); row = []; cell = ""; }
    else cell += ch;
  }
  if (quoted) throw new InputError("unterminated quote in CSV");
  if (cell !== "" || row.length > 0) { row.push(cell.replace(/\r$/, "")); rows.push(row); }
  return rows.filter((r) => r.some((c) => c.trim() !== ""));
}

function toRows(text: string, columns: string[], label: string): Row[] {
  const [header, ...lines] = parseCsv(text);
  if (!header) throw new InputError(`${label}: empty file`);
  const personal = header.filter((h) => PERSONAL_COLUMN.test(h.trim()));
  if (personal.length) throw new InputError(`${label}: remove personal columns: ${personal.join(", ")}`);
  const missing = columns.filter((c) => !header.includes(c));
  if (missing.length) throw new InputError(`${label}: missing columns: ${missing.join(", ")}`);
  return lines.map((cells, i) => {
    if (cells.length !== header.length) throw new InputError(`${label} line ${i + 2}: ${cells.length} cells, expected ${header.length}`);
    return Object.fromEntries(header.map((h, j) => [h, (cells[j] ?? "").trim()]));
  });
}

function monthly(row: Row, where: string): { amount: number; currency: string; basis: string } | null {

export function medianOrRefuse(values: number[]): Stat {
  if (values.length < MIN_N) return { kind: "refused", n: values.length };
  const sorted = [...values].sort((a, b) => a - b);
  const mid = sorted.length >> 1;
  const value = sorted.length % 2 ? sorted[mid]! : (sorted[mid - 1]! + sorted[mid]!) / 2;
  return { kind: "median", n: sorted.length, value };
}

  const hosts: string[] = [];
  const live: Row[] = [];
  let duplicates = 0;
  let stale = 0;

  rows.forEach((row, i) => {
    const where = `postings line ${i + 2}`;
    const url = canonicalUrl(row.url!, where);
    hosts.push(url.hostname);
    const key = url.href.toLowerCase();
    const age = (today - parseDate(row.date!, where)) / 86_400_000;
    if (age < 0) throw new InputError(`${where}: date is after as-of`);
    if (seen.has(key)) { duplicates++; return; }
    seen.add(key);
    if (age > MAX_AGE_DAYS) { stale++; return; }
    live.push(row);
  });

  // الـ sample المخترع مينفعش يتخلط ببيانات حقيقية
  const fake = hosts.filter((h) => h.endsWith(".invalid")).length;
  if (fake > 0 && fake < hosts.length) throw new InputError("postings mix invented .invalid rows with real rows: replace all of them");

  const textOf = (r: Row) => `${r.title} ${r.stack}`;
  const share = (test: (r: Row) => boolean) => (live.length ? live.filter(test).length / live.length : 0);
  const salaries = live.map((r, i) => ({ r, pay: monthly(r, `live posting ${i + 1}`) }));
  const stated = salaries.filter((s) => s.pay !== null);

  const calls = toRows(callsCsv, CALL_COLUMNS, "calls");
  calls.forEach((c, i) => {
    if (PERSONAL_VALUE.test(c.note ?? "")) throw new InputError(`calls line ${i + 2}: note looks like personal contact data`);
  });
  const callPay = calls.map((c, i) => ({ c, pay: monthly(c, `calls line ${i + 2}`) })).filter((x) => x.pay !== null);
  const moved = calls.filter((c) => c.moved_erp_to_product === "yes");

  const postingMedians = groupMedians(stated.map((s) => ({ key: `${trackOf(textOf(s.r))} ${s.pay!.currency}`, amount: s.pay!.amount })));
  const callMedians = groupMedians(callPay.map((x) => ({ key: `${x.c.track} ${x.pay!.currency}`, amount: x.pay!.amount })));
  const coverage = live.length ? stated.length / live.length : 0;
  const reasons: string[] = [];
  if (live.length < TARGET_POSTINGS) reasons.push(`only ${live.length} live postings, target ${TARGET_POSTINGS}`);
  if (coverage < TARGET_COVERAGE) reasons.push(`salary stated in ${Math.round(coverage * 100)}% of postings, target ${TARGET_COVERAGE * 100}%`);
  if (calls.length < TARGET_CALLS) reasons.push(`only ${calls.length} calls, target ${TARGET_CALLS}`);
  // لو الرقم اللي جاي عشانه اترفض، الثقة متبقاش أعلى من low
  const hasOdooMedian = Object.entries({ ...postingMedians, ...callMedians }).some(([k, v]) => k.startsWith("odoo ") && v.kind === "median");
  if (!hasOdooMedian) reasons.push("no Odoo median: the comparison this report exists for is refused");

  const remote: Record<string, number> = {};
  for (const r of live) remote[r.remote!] = (remote[r.remote!] ?? 0) + 1;

  return {
    invented: fake > 0,
    rows: rows.length,
    duplicates,
    stale,
    live: live.length,
    odooShare: share((r) => names.odoo.test(textOf(r))),
    erpShare: share((r) => names.odoo.test(textOf(r)) || names.erp.test(textOf(r))),
    hybridShare: share((r) => names.node.test(textOf(r)) && (names.odoo.test(textOf(r)) || names.erp.test(textOf(r)))),
    salaryCoverage: coverage,
    remote,
    postingMedians,
    callMedians,
    bases: [...new Set([...stated.map((s) => s.pay!.basis), ...callPay.map((x) => x.pay!.basis)])].sort(),
    calls: calls.length,
    movedBackNoDiscount: moved.filter((c) => c.level_discount === "no").length,
    movedBackWithDiscount: moved.filter((c) => c.level_discount === "yes").length,
    confidence: live.length < 10 ? "insufficient" : reasons.length ? "low" : "medium",
    reasons,
  };
}

const pct = (x: number) => `${Math.round(x * 100)}%`;
const showStat = (s: Stat) => (s.kind === "median" ? `median ${s.value.toFixed(0)} per month (n=${s.n})` : `REFUSED: n=${s.n} is below ${MIN_N}`);

export function render(r: Report, asOf: string): string {
  const out: string[] = [];
  if (r.invented) out.push("*** INVENTED SAMPLE: every row is made up. Do not cite these numbers. ***");
  out.push(`as of ${asOf}: ${r.rows} rows, ${r.duplicates} duplicates, ${r.stale} stale, ${r.live} live`);
  out.push(`names Odoo: ${pct(r.odooShare)} | names Odoo or another ERP: ${pct(r.erpShare)} | Node/TS plus ERP: ${pct(r.hybridShare)}`);
  out.push(`salary stated: ${pct(r.salaryCoverage)} | remote: ${JSON.stringify(r.remote)}`);
  out.push("posting medians:");
  for (const [key, stat] of Object.entries(r.postingMedians)) out.push(`  ${key.padEnd(16)} ${showStat(stat)}`);
  out.push(`calls logged: ${r.calls}`);
  for (const [key, stat] of Object.entries(r.callMedians)) out.push(`  ${key.padEnd(16)} ${showStat(stat)}`);
  out.push(`moved from ERP to product: ${r.movedBackNoDiscount} without a level discount, ${r.movedBackWithDiscount} with one`);
  if (r.bases.length > 1) out.push(`warning: mixed pay bases (${r.bases.join(", ")}): a median across them is rough`);
  out.push(`confidence: ${r.confidence} (ceiling for a hand sample: medium)`);
  for (const reason of r.reasons) out.push(`  - ${reason}`);
  return out.join("\n");
}

Exit test question 12 asks: do you enter ERP as a career or as a domain? Justify it with numbers you collected yourself. The report gives four conditions that would change its recommendation. The thresholds are the report author's judgement, not market facts.

  1. A real offer: an ERP role with ownership of production, integrations and performance with stated load numbers, and pay above the backend P75 in Egypt (EGP 60,625), or paid in dollars, or a Gulf total package above AED 25,000.
  2. Data you collected: an Odoo developer at 4–5 years repeatedly comes in above the backend median (EGP 44,000). That flips the financial argument.
  3. Typecasting evidence: three or more people who left ERP for product engineering without a level discount.
  4. A change of goal: you want to be a founder, open a partner firm, or be a solution consultant who owns the client, rather than a Staff engineer. Then Odoo is quite reasonable.

The script encodes these as checks that return fired, not-fired or unknown. "Repeatedly" is implemented as a median above the threshold on n ≥ 5, which is one reasonable reading; change it if you read it differently. One more caution: if the survey really dates from 2024, EGP 44,000 and 60,625 are low bars for a 2026 offer, so check the survey again when you decide. The inputs ship as null because I don't know your numbers, and with nothing filled in the tool refuses to decide.

import { pathToFileURL } from "node:url";

// العتبات دي حكم كاتب التقرير، مش حقيقة عن السوق
export const THRESHOLDS = {
  backendMedianEgp: 44_000,
  backendP75Egp: 60_625,
  gulfTotalAed: 25_000,
  minSample: 5,
  minCalls: 5,
  movedBackPeople: 3,
};

export interface Offer {
  ownsProduction: boolean;
  ownsIntegrations: boolean;
  statedLoadNumbers: boolean;
  monthlyPay: { currency: string; amount: number; basis: "net" | "gross" | "total" | "unknown" };
}

export interface Inputs {
  offer: Offer | null;
  odooMedian: { n: number; currency: string; amount: number; yearsFrom: number; yearsTo: number } | null;
  callsLogged: number | null;
  movedBackWithoutDiscount: number | null;
  goal: "staff-engineer" | "founder-or-partner" | "solution-consultant" | null;
}

export type Status = "fired" | "not-fired" | "unknown";
export interface Check {
  condition: string;
  status: Status;
  why: string;
}

function realOffer(offer: Offer | null): Check {
  const condition = "1. a real offer";
  if (!offer) return { condition, status: "unknown", why: "no offer to evaluate" };
  const engineering = offer.ownsProduction && offer.ownsIntegrations && offer.statedLoadNumbers;
  const { currency, amount, basis } = offer.monthlyPay;
  const pays =
    (currency === "EGP" && amount > THRESHOLDS.backendP75Egp) ||
    currency === "USD" ||
    (currency === "AED" && basis === "total" && amount > THRESHOLDS.gulfTotalAed);
  return {
    condition,
    status: engineering && pays ? "fired" : "not-fired",
    why: `engineering ownership: ${engineering}; pay clears a threshold: ${pays}`,
  };
}

function collectedData(median: Inputs["odooMedian"]): Check {
  const condition = "2. data you collected";
  if (!median) return { condition, status: "unknown", why: "no Odoo median yet" };
  if (median.n < THRESHOLDS.minSample) return { condition, status: "unknown", why: `n=${median.n} is below ${THRESHOLDS.minSample}` };
  if (median.currency !== "EGP") return { condition, status: "unknown", why: "the baseline is in EGP; compare like with like" };
  if (median.yearsFrom < 4 || median.yearsTo > 5) return { condition, status: "unknown", why: "the condition is about 4-5 years of experience" };
  const above = median.amount > THRESHOLDS.backendMedianEgp;
  return { condition, status: above ? "fired" : "not-fired", why: `Odoo median ${median.amount} against backend ${THRESHOLDS.backendMedianEgp}` };
}

function typecasting(calls: number | null, moved: number | null): Check {
  const condition = "3. typecasting evidence";
  if (moved !== null && moved >= THRESHOLDS.movedBackPeople) return { condition, status: "fired", why: `${moved} people moved back without a level discount` };
  if (calls === null || moved === null || calls < THRESHOLDS.minCalls) return { condition, status: "unknown", why: `needs at least ${THRESHOLDS.minCalls} calls` };
  return { condition, status: "not-fired", why: `${moved} of ${calls} calls, below ${THRESHOLDS.movedBackPeople}: still weak evidence` };
}

function goalChange(goal: Inputs["goal"]): Check {
  const condition = "4. a change of goal";
  if (!goal) return { condition, status: "unknown", why: "write your goal down first" };
  return { condition, status: goal === "staff-engineer" ? "not-fired" : "fired", why: `goal: ${goal}` };
}

export function evaluate(inputs: Inputs): { checks: Check[]; verdict: string } {
  const checks = [realOffer(inputs.offer), collectedData(inputs.odooMedian), typecasting(inputs.callsLogged, inputs.movedBackWithoutDiscount), goalChange(inputs.goal)];
  const fired = checks.filter((c) => c.status === "fired").length;
  const unknown = checks.filter((c) => c.status === "unknown").length;
  const verdict =
    fired > 0
      ? `${fired} condition(s) fired: re-examine the recommendation and record why`
      : unknown > 0
        ? `no decision from data yet: ${unknown} of ${checks.length} conditions unknown`
        : "no condition fired: the recommendation stands, as an inference";
  return { checks, verdict };
}

Solution · الحل 
// الحل: الربعيات محتاجة عينة أكبر من الـ median، فعتبتها 10
const MIN_N_SPREAD = 10;

type Spread =
  | { kind: "spread"; n: number; p25: number; p75: number }
  | { kind: "refused"; n: number };

function percentile(sorted: number[], p: number): number {
  const rank = (sorted.length - 1) * p;
  const low = Math.floor(rank);
  const high = Math.ceil(rank);
  return sorted[low]! + (sorted[high]! - sorted[low]!) * (rank - low);
}

function spreadOrRefuse(values: number[]): Spread {
  if (values.length < MIN_N_SPREAD) return { kind: "refused", n: values.length };
  const sorted = [...values].sort((a, b) => a - b);
  return { kind: "spread", n: sorted.length, p25: percentile(sorted, 0.25), p75: percentile(sorted, 0.75) };
}
