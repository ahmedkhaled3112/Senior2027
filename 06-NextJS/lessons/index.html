Next.js هو المكان اللي الـ frontend بيقابل فيه الـ backend، والـ caching بتاعه هو أكتر حاجة بتتكسر وأكتر حاجة اتغيرت: النهارده الموديل الأساسي هو Cache Components. السنيور بيعرف لكل route هيتعمله render إمتى وفين، وإيه اللي بيعمله invalidate، وليه.

طريقة المذاكرة: كل درس فيه أجزاء متعلّمة بالمستوى (🟢 / 🟡 / 🔴). لو عايز تمشي بالمستوى، اعمل الأجزاء الـ 🟢 في كل الدروس الأول. ولو بالموضوع، امشي بالترتيب. شغّل كل كود بإيدك، وحل التمارين قبل ما تفتح الحل.

بعد كل درس: علّم البنود في README.md وشغّل node _tools/update-progress.js.
