Why this matters · ليه ده مهم

Many product companies skip the graph puzzles and ask you to build a small thing their own code depends on: a cache, a limiter, an event bus, a pool, a parser. Part 1 — LRU cache 🟡 Intermediateالجزء 1 — الـ LRU cache

English
⏱ Timed prompt · 20 minutes Checkout reads product prices constantly and the pricing service is slow. Write LruCache<K, V> with get(key), set(key, value) and a fixed capacity. When it's full, adding a new key drops the key used longest ago; a read counts as use, and so does an overwrite. Both calls stay fast at any size. Deliver tests for eviction order, overwrite and capacity 1. If you finish early: expire entries after a TTL, then make a concurrent getOrLoad call the loader only once.
⏱ التمرين بالتوقيت: 20 دقيقة. الـ checkout بيقرا أسعار المنتجات طول الوقت والـ pricing service بطيء. اكتب LruCache<K, V> فيه get(key) و set(key, value) وسعة ثابتة. لما يتملى، إضافة key جديد بتشيل الـ key اللي بقاله أطول وقت من غير استخدام، والقراية بتتحسب استخدام والـ overwrite كمان. الاتنين لازم يفضلوا سريعين مهما كبر الحجم. سلّم tests لترتيب الـ eviction والـ overwrite وسعة 1. لو خلصت بدري: انتهاء بـ TTL، وبعدين getOrLoad متزامن ينادي الـ loader مرة واحدة بس.

Clarify in 30 seconds. Can a stored value be undefined? (Assume yes, so get must use has.) Is capacity 0 valid? (Reject it.) Any threads? (No: one event loop, so no locks.)

Brute force first. An array ordered oldest to newest. Every call scans it: O(n) per call, so n calls on a full cache are O(n²). Claim before measuring: the op counter prints x4 per doubling.

Final. A Map iterates in insertion order, so delete then set moves a key to the end, and the first key is always the oldest. That's O(1) average per call, O(n) for n calls: the counter should print x2. For the classic hash map plus doubly linked list, see the hash tables and LRU lesson; say it exists, and that its O(1) doesn't depend on engine internals.

The trap the counter can't see. Most answers evict with this.map.keys().next().value. V8's Map is an ordered hash table: deleted entries stay as holes until the next rehash, and a new iterator starts at the beginning and walks over them. An LRU deletes from the front, so every eviction pays for all the holes since the last rehash. My counter counts calls, so it still says x2, and only the clock shows it. The fix is one line: keep a single iterator for the life of the cache. It never moves backwards, so each hole is walked once. It's safe here because next() runs only when the map is full, so it can't run out, and the key it returns is deleted at once, so no live key is ever behind it.

Follow-ups. TTL: store expiresAt with the value, take an injected clock, and expire lazily on read, with no timer per key. Single-flight: an in-flight Map from key to promise, so 100 concurrent misses make one load; remove it in finally so a failed load isn't cached. The production version of this problem is in cache stampede and hot keys.

// الـ brute force: array مترتبة من الأقدم للأحدث، وكل عملية بتلف عليها
export class LruArray<K, V> {
  private readonly entries: { key: K; value: V }[] = [];
  private readonly capacity: number;
  private readonly tick: () => void;

  constructor(capacity: number, tick: () => void = () => {}) {
    this.capacity = capacity;
    this.tick = tick;
  }

  private find(key: K): number {
    for (let i = 0; i < this.entries.length; i++) {
      this.tick();
      if (this.entries[i].key === key) return i;
    }
    return -1;
  }

  get(key: K): V | undefined {
    const i = this.find(key);
    if (i === -1) return undefined;
    const [entry] = this.entries.splice(i, 1);
    this.entries.push(entry);
    return entry.value;
  }

  delete(key: K): boolean {
    const i = this.find(key);
    if (i === -1) return false;
    this.entries.splice(i, 1);
    return true;
  }

  set(key: K, value: V): void {
    const i = this.find(key);
    if (i !== -1) this.entries.splice(i, 1);
    else if (this.entries.length === this.capacity) this.entries.shift();
    this.entries.push({ key, value });
  }
}
// الـ Map بتحفظ ترتيب الإدخال: أول key فيها هو الأقدم استخدامًا
export class LruCache<K, V> {
  private readonly capacity: number;
  private readonly map = new Map<K, V>();
  // ليه iterator واحد عايش طول عمر الـ cache؟ الإجابة في القياس تحت
  private readonly oldestKeys = this.map.keys();
  // الـ tick ده للقياس بس، وفي الـ interview مش هتكتبه
  private readonly tick: () => void;

  constructor(capacity: number, tick: () => void = () => {}) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`capacity must be a positive integer, got ${capacity}`);
    }
    this.capacity = capacity;
    this.tick = tick;
  }

  get size(): number {
    return this.map.size;
  }

  get(key: K): V | undefined {
    this.tick();
    // لازم has: ممكن تكون القيمة المتخزنة نفسها undefined
    if (!this.map.has(key)) return undefined;
    const value = this.map.get(key) as V;
    // المسح وإعادة الإدخال بينقلوا الـ key لآخر الترتيب
    this.map.delete(key);
    this.map.set(key, value);
    return value;
  }

  set(key: K, value: V): void {
    this.tick();
    if (this.map.has(key)) {
      this.map.delete(key);
    } else if (this.map.size === this.capacity) {
      // هنا الـ map مليانة، فالـ iterator عمره ما هيخلص
      this.map.delete(this.oldestKeys.next().value as K);
    }
    this.map.set(key, value);
  }

  delete(key: K): boolean {
    this.tick();
    return this.map.delete(key);
  }
}

type Stamped<V> = { value: V; expiresAt: number };

// الساعة بتتحقن من بره عشان الـ test يقف عند ميلّي ثانية بالظبط
export class TtlLruCache<K, V> {
  private readonly entries: LruCache<K, Stamped<V>>;
  private readonly inFlight = new Map<K, Promise<V>>();
  private readonly ttlMs: number;
  private readonly now: () => number;

  constructor(capacity: number, ttlMs: number, now: () => number = Date.now) {
    this.entries = new LruCache(capacity);
    this.ttlMs = ttlMs;
    this.now = now;
  }

  get(key: K): V | undefined {
    const hit = this.entries.get(key);
    if (hit === undefined) return undefined;
    // الانتهاء كسول: مفيش timer لكل key، بنشيله لما حد يطلبه
    if (hit.expiresAt <= this.now()) {
      this.entries.delete(key);
      return undefined;
    }
    return hit.value;
  }

  set(key: K, value: V): void {
    this.entries.set(key, { value, expiresAt: this.now() + this.ttlMs });
  }

  // الـ single-flight: 100 request على نفس الـ key بيعملوا load واحد
  getOrLoad(key: K, load: (key: K) => Promise<V>): Promise<V> {
    const hit = this.get(key);
    if (hit !== undefined) return Promise.resolve(hit);
    const running = this.inFlight.get(key);
    if (running) return running;

    const loading = (async () => {
      try {
        const value = await load(key);
        this.set(key, value);
        return value;
      } finally {
        // الـ finally بيضمن إن الـ load الفاشل ميتخزنش، واللي بعده يحاول تاني
        this.inFlight.delete(key);
      }
    })();
    this.inFlight.set(key, loading);
    return loading;
  }
}

// لو الـ ops بتتضاعف x2 يبقى ⁦O(n)⁩، ولو x4 يبقى ⁦O(n²)⁩، ولو أكتر من x2 شوية يبقى ⁦O(n log n)⁩
function line(name: string, n: number, ops: number, ms: number, prev: { ops: number; ms: number } | null): void {
  const opsRatio = prev ? 'x' + (ops / prev.ops).toFixed(2) : '';
  const msRatio = prev ? 'x' + (ms / Math.max(prev.ms, 0.01)).toFixed(2) : '';
  console.log(`${name.padEnd(10)} n=${String(n).padStart(8)} ops=${String(ops).padStart(12)} ${opsRatio.padEnd(6)} ms≈${ms.toFixed(1)} ${msRatio}`);
}

export function doubling(name: string, run: (n: number, tick: () => void) => void, sizes: number[]): void {
  let prev: { ops: number; ms: number } | null = null;
  for (const n of sizes) {
    let ops = 0;
    const started = performance.now();
    run(n, () => { ops++; });
    const ms = performance.now() - started;
    line(name, n, ops, ms, prev);
    prev = { ops, ms };
  }
}

// نفس الأداة للكود اللي بيستنى promises
export async function doublingAsync(name: string, run: (n: number, tick: () => void) => Promise<void>, sizes: number[]): Promise<void> {
  let prev: { ops: number; ms: number } | null = null;
  for (const n of sizes) {
    let ops = 0;
    const started = performance.now();
    await run(n, () => { ops++; });
    const ms = performance.now() - started;
    line(name, n, ops, ms, prev);
    prev = { ops, ms };
  }
}

// الشكل المشهور اللي بتلاقيه في أغلب الإجابات: iterator جديد في كل eviction
class LruFreshIterator<K, V> {
  private readonly map = new Map<K, V>();
  private readonly capacity: number;
  private readonly tick: () => void;

  constructor(capacity: number, tick: () => void) {
    this.capacity = capacity;
    this.tick = tick;
  }

  set(key: K, value: V): void {
    this.tick();
    if (this.map.has(key)) this.map.delete(key);
    else if (this.map.size === this.capacity) this.map.delete(this.map.keys().next().value as K);
    this.map.set(key, value);
  }
}

  for (let i = 0; i < 2 * n; i++) cache.set(i, i);

بالعامية

وضّح في 30 ثانية. ممكن القيمة المتخزنة تبقى undefined؟ (افترض آه، فالـ get لازم يستخدم has.) السعة 0 مقبولة؟ (ارفضها.) فيه threads؟ (لأ: event loop واحد، فمفيش locks.)

الـ brute force الأول. array مترتبة من الأقدم للأحدث، وكل نداء بيلف عليها: O(n) للنداء، يعني n نداء على cache مليان O(n²). الإجابة قبل القياس: العداد هيطبع x4 مع كل مضاعفة.

الحل النهائي. الـ Map بتلف بترتيب الإدخال، فـ delete وبعدها set بينقلوا الـ key للآخر، وأول key دايمًا هو الأقدم. ده O(1) في المتوسط للنداء و O(n) لـ n نداء، فالعداد المفروض يطبع x2. ونسخة الـ hash map مع doubly linked list موجودة في درس الـ hash tables والـ LRU: قول إنها موجودة، وإن الـ O(1) بتاعها مش معتمد على تفاصيل المحرك.

الفخ اللي العداد مش شايفه. أغلب الإجابات بتعمل eviction بـ this.map.keys().next().value. الـ Map في V8 عبارة عن ordered hash table: العناصر الممسوحة بتفضل holes لحد الـ rehash الجاي، والـ iterator الجديد بيبدأ من الأول ويلف عليهم. الـ LRU بيمسح من الأول، فكل eviction بتدفع تمن كل الـ holes من آخر rehash. العداد بتاعي بيعدّ النداءات، فهيفضل يقول x2، والساعة بس اللي بتكشفها. الحل سطر واحد: iterator واحد طول عمر الـ cache. مش بيرجع لورا أبدًا، فكل hole بيتمشي عليها مرة واحدة. ده آمن هنا لأن next() بتتنادى بس لما الـ map تبقى مليانة، فمش هيخلص، والـ key اللي بيرجعه بيتمسح على طول، فمفيش key حي وراه أبدًا.

الـ follow-ups. الـ TTL: خزّن expiresAt مع القيمة، خد clock متحقن، وخلّي الانتهاء كسول وقت القراية من غير timer لكل key. الـ single-flight: Map من الـ key للـ promise، فـ 100 miss متزامنين يعملوا load واحد، وامسحه في finally عشان الـ load الفاشل ميتخزنش. والنسخة بتاعة production من المشكلة دي في درس الـ cache stampede والـ hot keys.

الغلطة الشائعة هنا: if (!value) return undefined في الـ get: السعر 0 أو القيمة "" بيتعاملوا كأنهم مش موجودين، والـ cache يعمل miss على حاجة موجودة.

Brute force first. Store every request's timestamp per key and filter the list on each call. O(requests in the window) per call, and the same in memory: the counter should print x4.

Final: a token bucket with lazy refill. No timer tops the bucket up. On each call, compute how many tokens have accumulated since the last one. O(1) time, O(1) memory per key: x2. The algorithms are compared in the rate limiter pattern lesson and the distributed one. What the interview adds is three things:

  1. The fast path. No I/O, no scan, no timers. If the clock didn't move or the bucket is already full, skip the arithmetic. A denial must be as cheap as an approval, because denials are what you see under attack.
  2. Exact timestamps. Test 99 ms and 100 ms, not "about a second". Floats drift here: ten refills of 1 ms at 100 tokens per second add up to 0.9999999999999999, so a request at exactly 10 ms is denied. The model counts integer micro-tokens instead, the same reason you store money in cents. retryAfterMs uses Math.ceil, so a client that waits exactly that long succeeds.
  3. Memory for idle keys. A bucket that has fully refilled behaves exactly like no bucket, so deleting it changes no decision. sweepIdle() does that; the caller runs it every minute. A hard cap is exercise 2.

Multi-instance. With two servers each one has its own buckets, so a key gets twice the limit. The answer is Redis with an atomic check-and-update (a Lua script or a server-side counter). Name it and move on: building it isn't what the 25 minutes are for.

// الـ brute force: نخزن وقت كل request ونعدّهم من الأول في كل مرة
export class TimestampLogLimiter {
  private readonly hits = new Map<string, number[]>();
  private readonly limit: number;
  private readonly windowMs: number;
  private readonly now: () => number;
  private readonly tick: () => void;

  constructor(limit: number, windowMs: number, now: () => number, tick: () => void = () => {}) {
    this.limit = limit;
    this.windowMs = windowMs;
    this.now = now;
    this.tick = tick;
  }

  tryConsume(apiKey: string): boolean {
    const cutoff = this.now() - this.windowMs;
    const recent = (this.hits.get(apiKey) ?? []).filter((at) => {
      this.tick();
      return at > cutoff;
    });
    const allowed = recent.length < this.limit;
    if (allowed) recent.push(this.now());
    this.hits.set(apiKey, recent);
    return allowed;
  }
}
export type ConsumeResult = { allowed: boolean; remaining: number; retryAfterMs: number };

type Bucket = { microTokens: number; refilledAt: number };

// التوكن الواحد = مليون وحدة، عشان الحساب كله integers ومفيش float drift
const MICRO_PER_TOKEN = 1_000_000;

export class TokenBucketLimiter {
  private readonly buckets = new Map<string, Bucket>();
  private readonly fullMicro: number;
  private readonly microPerMs: number;
  private readonly now: () => number;
  private readonly tick: () => void;

  constructor(
    options: { capacity: number; refillPerSecond: number; now?: () => number },
    tick: () => void = () => {},
  ) {
    const { capacity, refillPerSecond, now = Date.now } = options;
    if (!Number.isInteger(capacity) || capacity < 1) throw new RangeError("capacity must be a positive integer");
    if (!Number.isInteger(refillPerSecond) || refillPerSecond < 1) throw new RangeError("refillPerSecond must be a positive integer");
    this.fullMicro = capacity * MICRO_PER_TOKEN;
    this.microPerMs = (refillPerSecond * MICRO_PER_TOKEN) / 1000;
    this.now = now;
    this.tick = tick;
  }

  tryConsume(apiKey: string, cost = 1): ConsumeResult {
    this.tick();
    const costMicro = cost * MICRO_PER_TOKEN;
    if (!Number.isInteger(cost) || cost < 1 || costMicro > this.fullMicro) {
      throw new RangeError(`cost must be an integer between 1 and the capacity, got ${cost}`);
    }
    const bucket = this.refill(apiKey, this.now());
    if (bucket.microTokens >= costMicro) {
      bucket.microTokens -= costMicro;
      return { allowed: true, remaining: Math.floor(bucket.microTokens / MICRO_PER_TOKEN), retryAfterMs: 0 };
    }
    const missing = costMicro - bucket.microTokens;
    // الـ ceil مهم: لو رجّعت floor، الـ client هيرجع بدري بميلّي ثانية ويترفض تاني
    return {
      allowed: false,
      remaining: Math.floor(bucket.microTokens / MICRO_PER_TOKEN),
      retryAfterMs: Math.ceil(missing / this.microPerMs),
    };
  }

  // مفيش timers: الـ tokens بتتحسب كسول من الوقت اللي فات
  private refill(apiKey: string, now: number): Bucket {
    const bucket = this.buckets.get(apiKey);
    if (!bucket) {
      const fresh: Bucket = { microTokens: this.fullMicro, refilledAt: now };
      this.buckets.set(apiKey, fresh);
      return fresh;
    }
    // الـ fast path: ساعة واقفة أو راجعة لورا أو bucket مليان، يبقى مفيش حساب
    const elapsed = now - bucket.refilledAt;
    if (elapsed <= 0) return bucket;
    bucket.refilledAt = now;
    if (bucket.microTokens === this.fullMicro) return bucket;
    bucket.microTokens = Math.min(this.fullMicro, bucket.microTokens + elapsed * this.microPerMs);
    return bucket;
  }

  // الـ bucket اللي امتلى زي key جديد بالظبط، فمسحه مش بيغيّر أي سلوك
  sweepIdle(): number {
    const now = this.now();
    let removed = 0;
    for (const [apiKey, bucket] of this.buckets) {
      this.tick();
      const refilled = bucket.microTokens + (now - bucket.refilledAt) * this.microPerMs;
      if (refilled >= this.fullMicro && this.buckets.delete(apiKey)) removed++;
    }
    return removed;
  }

  get trackedKeys(): number {
    return this.buckets.size;
  }
}

بالعامية

الـ brute force الأول. خزّن وقت كل request لكل key وفلتر اللستة في كل نداء. O(عدد الـ requests في الـ window) للنداء، ونفس الشيء في الذاكرة، فالعداد المفروض يطبع x4.

الحل النهائي: token bucket بـ lazy refill. مفيش timer بيملا الـ bucket. في كل نداء احسب كام توكن اتجمع من آخر نداء. O(1) وقت و O(1) ذاكرة لكل key: يعني x2. الخوارزميات متقارنة في درس الـ rate limiter pattern ودرس الـ distributed. الـ interview بيزوّد 3 حاجات:

  1. الـ fast path. مفيش I/O ولا scan ولا timers. لو الساعة متحركتش أو الـ bucket مليان، سيب الحساب. الرفض لازم يبقى رخيص زي القبول، لأن الرفض هو اللي بتشوفه وقت الهجوم.
  2. الـ timestamps بالظبط. اختبر 99 ms و 100 ms، مش "حوالي ثانية". الـ floats بتنحرف هنا: 10 refills كل واحد 1 ms بمعدل 100 توكن في الثانية مجموعهم 0.9999999999999999، فـ request عند 10 ms بالظبط بيترفض. الحل النموذجي بيعدّ micro-tokens كـ integers، لنفس السبب اللي بتخزن بيه الفلوس بالقروش. والـ retryAfterMs بيستخدم Math.ceil، فالـ client اللي يستنى الوقت ده بالظبط ينجح.
  3. الذاكرة للـ keys الخاملة. الـ bucket اللي امتلى خالص زي مفيش bucket بالظبط، فمسحه مش بيغيّر أي قرار. الـ sweepIdle() بتعمل كده، والـ caller بيشغّلها كل دقيقة. والحد الأقصى الصريح هو التمرين 2.

لو فيه كذا instance. مع سيرفرين كل واحد عنده buckets لوحده، فالـ key بياخد ضعف الحد. الإجابة: Redis مع check-and-update ذرّي (Lua script أو counter على السيرفر). سمّيها وكمّل: مش ده اللي الـ 25 دقيقة معمولة عشانه.

الغلطة الشائعة: setInterval لكل key يملا الـ tokens: مع 100,000 key يبقى عندك 100,000 timer شغالين طول الوقت، والـ memory بتاعتهم مش بتتسيّب.

Brute force first. An array per event. off scans it, so n listeners removing themselves cost O(n²): x4. The worse problem is a bug: emit loops over the live array, a listener that removes itself shifts everything left, and the next listener is skipped. The test below shows it.

Final. A Map per event, keyed by the listener: on and off are O(1) (x2), and off finds a once registration because the key is the original function, with no wrapper to chase. emit iterates a snapshot, [...channel], so listeners can add and remove themselves freely. Node's own EventEmitter copies the same way.

Policies to say out loud. One listener throwing doesn't stop the others; the error goes to a handler the constructor requires, and a rejected promise from an async listener goes to the same place. Node's EventEmitter does the opposite: the first throw stops the rest and reaches the caller of emit. Registering the same function twice counts once here, where Node counts it twice. Neither is wrong, but you need to have picked one. Background: observer and events and async patterns.

Debounce and throttle. Debounce waits for quiet and keeps only the latest call: search-as-you-type and autosave. Throttle guarantees at most one call per interval, leading plus one trailing: progress updates and scroll handlers. Test them with mock.timers from node:test, which needs no real waiting.

// الـ brute force: array لكل event، و off بتدور جواها، و emit بتلف عليها مباشرة
type Handler = (payload: unknown) => void;

export class ArrayEmitter {
  private readonly listeners = new Map<string, Handler[]>();
  private readonly tick: () => void;

  constructor(tick: () => void = () => {}) {
    this.tick = tick;
  }

  on(event: string, handler: Handler): void {
    const handlers = this.listeners.get(event) ?? [];
    handlers.push(handler);
    this.listeners.set(event, handlers);
  }

  off(event: string, handler: Handler): void {
    const handlers = this.listeners.get(event) ?? [];
    for (let i = 0; i < handlers.length; i++) {
      this.tick();
      if (handlers[i] === handler) {
        handlers.splice(i, 1);
        return;
      }
    }
  }

  emit(event: string, payload: unknown): void {
    // الغلطة: بنلف على نفس الـ array اللي الـ listener ممكن يغيّرها
    const handlers = this.listeners.get(event) ?? [];
    for (let i = 0; i < handlers.length; i++) handlers[i](payload);
  }
}
type Listener<P> = (payload: P) => void;
type Entry<P> = { listener: Listener<P>; once: boolean };

// الـ policy: كل listener بيشتغل، والـ errors بتروح لـ handler إنت لازم تحدده
export type ListenerErrorHandler<Events> = (error: unknown, event: keyof Events) => void;

export class TypedEmitter<Events extends Record<string, unknown>> {
  private readonly channels = new Map<keyof Events, Map<unknown, Entry<never>>>();
  private readonly onListenerError: ListenerErrorHandler<Events>;
  private readonly tick: () => void;

  constructor(onListenerError: ListenerErrorHandler<Events>, tick: () => void = () => {}) {
    this.onListenerError = onListenerError;
    this.tick = tick;
  }

  on<K extends keyof Events>(event: K, listener: Listener<Events[K]>): () => void {
    return this.add(event, listener, false);
  }

  once<K extends keyof Events>(event: K, listener: Listener<Events[K]>): () => void {
    return this.add(event, listener, true);
  }

  off<K extends keyof Events>(event: K, listener: Listener<Events[K]>): void {
    this.tick();
    // الـ key هو الـ listener الأصلي، فـ off بتشتغل حتى مع once
    this.channels.get(event)?.delete(listener);
  }

  emit<K extends keyof Events>(event: K, payload: Events[K]): void {
    const channel = this.channels.get(event);
    if (!channel) return;
    // النسخة دي هي الحل: الـ listener يقدر يشيل نفسه من غير ما اللي بعده يتنط
    for (const [key, entry] of [...channel]) {
      this.tick();
      if (entry.once) channel.delete(key);
      this.invoke(event, entry as unknown as Entry<Events[K]>, payload);
    }
  }

  private add<K extends keyof Events>(event: K, listener: Listener<Events[K]>, once: boolean): () => void {
    this.tick();
    let channel = this.channels.get(event);
    if (!channel) {
      channel = new Map();
      this.channels.set(event, channel);
    }
    channel.set(listener, { listener, once } as unknown as Entry<never>);
    return () => this.off(event, listener);
  }

  private invoke<K extends keyof Events>(event: K, entry: Entry<Events[K]>, payload: Events[K]): void {
    try {
      // الـ listener الـ async بيرجع promise، ولازم نمسك الـ rejection بتاعه كمان
      const result: unknown = entry.listener(payload);
      if (result instanceof Promise) result.catch((error) => this.onListenerError(error, event));
    } catch (error) {
      this.onListenerError(error, event);
    }
  }
}
type Timer = ReturnType<typeof setTimeout>;

// الـ debounce: استنى لحد ما الدوشة تهدى، وشغّل آخر نداء بس
export function debounce<A extends unknown[]>(fn: (...args: A) => void, waitMs: number) {
  let timer: Timer | undefined;
  let pending: A | undefined;

  const fire = () => {
    timer = undefined;
    const args = pending as A;
    pending = undefined;
    fn(...args);
  };

  const debounced = (...args: A): void => {
    pending = args;
    clearTimeout(timer);
    timer = setTimeout(fire, waitMs);
  };
  debounced.cancel = (): void => {
    clearTimeout(timer);
    timer = undefined;
    pending = undefined;
  };
  debounced.flush = (): void => {
    if (timer === undefined) return;
    clearTimeout(timer);
    fire();
  };
  return debounced;
}

// الـ throttle: أول نداء فورًا، وآخر نداء بعد الـ interval، ومرة واحدة كل interval بالكتير
export function throttle<A extends unknown[]>(fn: (...args: A) => void, intervalMs: number) {
  let timer: Timer | undefined;
  let pending: A | undefined;

  const onInterval = () => {
    if (pending === undefined) {
      timer = undefined;
      return;
    }
    const args = pending;
    pending = undefined;
    timer = setTimeout(onInterval, intervalMs);
    fn(...args);
  };

  return (...args: A): void => {
    if (timer !== undefined) {
      pending = args;
      return;
    }
    timer = setTimeout(onInterval, intervalMs);
    fn(...args);
  };
}

Brute force first. Promise.all(tasks.map((t) => t())) starts everything at once, so the peak equals n and the service falls over. Claim: the peak grows as x2 per doubling; with a pool it stays at the limit. The next idea is Promise.race over the running set with splice: it respects the limit, but each loop touches every running promise. That's O(n·limit) and x4 when the limit grows with n, and it stacks a reaction on every long-lived promise.

Final: limit workers pulling from a shared index. Each worker loops: take next++, await that task, store the result at its own index. Scheduling is O(n): x2. The shared counter is safe because nothing awaits between reading it and incrementing it, and JS is single-threaded. Order comes for free from results[index].

Error policy, stated. Default: every task runs, and you get one PromiseSettledResult per task. With stopOnError: no new task starts, tasks already running finish, then the first error is thrown, so no work is left running after the function returns. Stopping tasks that are already running needs an AbortSignal passed into them. The async foundations are in advanced async.

// تاني brute force: عنده حد، بس بيعمل race على كل اللي شغال في كل خطوة
export async function runWithRace<T>(tasks: readonly Task<T>[], limit: number, tick: () => void = () => {}): Promise<T[]> {
  const results: T[] = new Array(tasks.length);
  const running: Promise<void>[] = [];

  for (let i = 0; i < tasks.length; i++) {
    const job: Promise<void> = tasks[i]().then((value) => {
      results[i] = value;
      running.splice(running.indexOf(job), 1);
      tick();
    });
    running.push(job);
    if (running.length >= limit) {
      // الـ race بيعلّق reaction على كل promise شغالة، يعني ⁦O(limit)⁩ في كل دورة
      for (let r = 0; r < running.length; r++) tick();
      await Promise.race(running);
    }
  }
  await Promise.all(running);
  return results;
}

export type PoolOptions = {
  limit: number;
  // لو true: أول فشل بيوقف بدء tasks جديدة، وبيستنى اللي شغال يخلص، وبيرمي أول error
  stopOnError?: boolean;
};

export async function runPool<T>(
  tasks: readonly Task<T>[],
  options: PoolOptions,
  tick: () => void = () => {},
): Promise<PromiseSettledResult<T>[]> {
  const { limit, stopOnError = false } = options;
  if (!Number.isInteger(limit) || limit < 1) {
    throw new RangeError(`limit must be a positive integer, got ${limit}`);
  }

  const results: PromiseSettledResult<T>[] = new Array(tasks.length);
  let next = 0;
  // ملفوف في object عشان الـ reason نفسه ممكن يبقى undefined
  let firstFailure: { reason: unknown } | undefined;

  // كل worker بيسحب الـ index اللي عليه الدور: مفيش race ولا splice
  const worker = async (): Promise<void> => {
    while (next < tasks.length && firstFailure === undefined) {
      tick();
      const index = next++;
      try {
        // الـ try بيمسك الـ rejection وكمان الـ throw المتزامن من الـ task
        results[index] = { status: "fulfilled", value: await tasks[index]() };
      } catch (reason) {
        results[index] = { status: "rejected", reason };
        if (stopOnError) firstFailure ??= { reason };
      }
    }
  };

  await Promise.all(Array.from({ length: Math.min(limit, tasks.length) }, worker));
  if (firstFailure) throw firstFailure.reason;
  return results;
}

// الـ brute force: لستة seen عادية، وكل object بيتدور عليه فيها من الأول
export function cloneWithSeenList(input: unknown, tick: () => void = () => {}): unknown {
  const seen: [object, object][] = [];

  const visit = (value: unknown): unknown => {
    if (typeof value !== "object" || value === null) return value;
    for (const [original, copy] of seen) {
      tick();
      if (original === value) return copy;
    }
    const out: Record<string, unknown> | unknown[] = Array.isArray(value) ? [] : {};
    seen.push([value, out]);
    for (const [key, item] of Object.entries(value)) {
      (out as Record<string, unknown>)[key] = visit(item);
    }
    return out;
  };

  return visit(input);
}

// الـ Buffer والـ Promise والـ WeakMap: TypeError بدل نسخة بايظة من غير ما تحس
export function deepClone<T>(input: T, tick: () => void = () => {}): T {
  const seen = new WeakMap<object, unknown>();

  const visit = (value: unknown): unknown => {
    if (typeof value === "function") throw new TypeError(`cannot clone function ${value.name || "(anonymous)"}`);
    if (typeof value !== "object" || value === null) return value;

    tick();
    // الـ WeakMap هو اللي بيكسر الـ cycles وبيحافظ على الـ shared references
    const known = seen.get(value);
    if (known !== undefined) return known;

    if (value instanceof Date) return remember(value, new Date(value.getTime()));
    if (value instanceof RegExp) {
      const copy = new RegExp(value.source, value.flags);
      copy.lastIndex = value.lastIndex;
      return remember(value, copy);
    }
    if (value instanceof Map) {
      const copy = new Map<unknown, unknown>();
      // التسجيل قبل النزول: الـ Map ممكن تحتوي على نفسها
      seen.set(value, copy);
      for (const [k, v] of value) copy.set(visit(k), visit(v));
      return copy;
    }
    if (value instanceof Set) {
      const copy = new Set<unknown>();
      seen.set(value, copy);
      for (const v of value) copy.add(visit(v));
      return copy;
    }
    if (ArrayBuffer.isView(value) || value instanceof ArrayBuffer || value instanceof Promise || value instanceof WeakMap || value instanceof WeakSet) {
      throw new TypeError(`cannot clone ${Object.prototype.toString.call(value)}`);
    }

    const copy: object = Array.isArray(value) ? [] : Object.create(Object.getPrototypeOf(value));
    seen.set(value, copy);
    // الـ defineProperty مش الـ assignment: الـ key اللي اسمه ⁦__proto__⁩ يفضل own property عادي
    for (const key of Reflect.ownKeys(value)) {
      const descriptor = Object.getOwnPropertyDescriptor(value, key) as PropertyDescriptor;
      if ("value" in descriptor) descriptor.value = visit(descriptor.value);
      Object.defineProperty(copy, key, descriptor);
    }
    return copy;
  };

  const remember = <C extends object>(original: object, copy: C): C => {
    seen.set(original, copy);
    return copy;
  };

  return visit(input) as T;
}

Brute force first. For each opening bracket, scan forward to find its match, then recurse on the inside. Every nesting level rescans the text inside it: O(n·depth), so [[[…]]] is O(n²) and the counter prints x4. (It's shown on a subset: arrays only.)

Final: recursive descent. One function per grammar rule and a single position that only moves forward: O(n), x2. Numbers use a sticky regex (/…/y with lastIndex), so they don't copy the rest of the string. Strings copy runs between escapes rather than one character at a time. Object keys go through defineProperty, for the same __proto__ reason as Part 5. Every failure carries a position.

Prove it, differentially. You can't enumerate JSON by hand. fc.json() from fast-check generates documents, and a test runs both parsers and compares: 3,000 seeded runs agreed. All 8 invalid inputs ({, [1,], a trailing comma in an object, 01, a raw newline inside a string, nul, trailing garbage, empty input) are rejected by both.

The follow-up: nesting depth. Recursion uses the call stack. On this machine the parser overflows at about 8,600 levels with a RangeError (the frame count varies with what the JIT did), while JSON.parse handled 200,000. Name that limit out loud, and cap it: maxDepth turns a crash into a normal parse error. Parsing untrusted input without a depth limit is a denial-of-service bug.

// الـ ⁦brute force (subset: arrays of numbers)⁩: لكل قوس ندور على القوس اللي بيقفله، وننزل جوه
export function parseArraysBrute(text: string, tick: () => void = () => {}): unknown {
  const body = text.trim();
  if (!body.startsWith("[")) return Number(body);

  // اللفة دي بتتكرر عند كل مستوى nesting، وده مصدر الـ ⁦O(n²)⁩
  let depth = 0;
  let closeAt = -1;
  for (let i = 0; i < body.length; i++) {
    tick();
    if (body[i] === "[") depth++;
    if (body[i] === "]" && --depth === 0) {
      closeAt = i;
      break;
    }
  }
  if (closeAt === -1) throw new SyntaxError("unbalanced brackets");

  const inner = body.slice(1, closeAt);
  if (inner.trim() === "") return [];

  const items: string[] = [];
  let start = 0;
  depth = 0;
  for (let i = 0; i < inner.length; i++) {
    tick();
    if (inner[i] === "[") depth++;
    if (inner[i] === "]") depth--;
    if (inner[i] === "," && depth === 0) {
      items.push(inner.slice(start, i));
      start = i + 1;
    }
  }
  items.push(inner.slice(start));
  return items.map((item) => parseArraysBrute(item, tick));
}

const NUMBER = /-?(?:0|[1-9]\d*)(?:\.\d+)?(?:[eE][+-]?\d+)?/y;
const SIMPLE_ESCAPES: Record<string, string> = {
  '"': '"', "\\": "\\", "/": "/", b: "\b", f: "\f", n: "\n", r: "\r", t: "\t",
};

export type ParseOptions = { maxDepth?: number; tick?: () => void };

// الـ recursive descent: دالة لكل قاعدة في الـ grammar، و pos واحد ماشي لقدام وبس
class Parser {
  private readonly text: string;
  private readonly maxDepth: number;
  private readonly tick: () => void;
  private pos = 0;
  private depth = 0;

  constructor(text: string, options: ParseOptions) {
    this.text = text;
    this.maxDepth = options.maxDepth ?? 512;
    this.tick = options.tick ?? (() => {});
  }

  parseDocument(): unknown {
    const value = this.parseValue();
    this.skipWhitespace();
    if (this.pos !== this.text.length) this.fail("unexpected trailing characters");
    return value;
  }

  private fail(message: string): never {
    throw new JsonParseError(message, this.pos);
  }

  private skipWhitespace(): void {
    while (this.pos < this.text.length && " \t\n\r".includes(this.text[this.pos])) {
      this.tick();
      this.pos++;
    }
  }

  private parseValue(): unknown {
    this.skipWhitespace();
    if (this.pos >= this.text.length) this.fail("unexpected end of input");
    this.tick();
    const char = this.text[this.pos];
    if (char === "{" || char === "[") {
      // حد العمق: error واضح بدل RangeError من الـ stack
      if (++this.depth > this.maxDepth) this.fail(`nesting deeper than ${this.maxDepth}`);
      const nested = char === "{" ? this.parseObject() : this.parseArray();
      this.depth--;
      return nested;
    }
    if (char === '"') return this.parseString();
    if (this.text.startsWith("true", this.pos)) return this.literal("true", true);
    if (this.text.startsWith("false", this.pos)) return this.literal("false", false);
    if (this.text.startsWith("null", this.pos)) return this.literal("null", null);
    return this.parseNumber();
  }

  private literal<T>(word: string, value: T): T {
    this.pos += word.length;
    return value;
  }

  private parseNumber(): number {
    // الـ sticky flag بيبدأ من pos بالظبط من غير ما ينسخ باقي النص
    NUMBER.lastIndex = this.pos;
    const match = NUMBER.exec(this.text);
    if (!match) this.fail("unexpected token");
    this.pos += match[0].length;
    return Number(match[0]);
  }

  private parseArray(): unknown[] {
    this.pos++;
    const items: unknown[] = [];
    this.skipWhitespace();
    if (this.text[this.pos] === "]") {
      this.pos++;
      return items;
    }
    for (;;) {
      items.push(this.parseValue());
      this.skipWhitespace();
      const char = this.text[this.pos];
      if (char === "]") {
        this.pos++;
        return items;
      }
      if (char !== ",") this.fail("expected ',' or ']'");
      this.pos++;
    }
  }

  private parseObject(): Record<string, unknown> {
    this.pos++;
    const out: Record<string, unknown> = {};
    this.skipWhitespace();
    if (this.text[this.pos] === "}") {
      this.pos++;
      return out;
    }
    for (;;) {
      this.skipWhitespace();
      if (this.text[this.pos] !== '"') this.fail("expected a string key");
      const key = this.parseString();
      this.skipWhitespace();
      if (this.text[this.pos] !== ":") this.fail("expected ':'");
      this.pos++;
      const value = this.parseValue();
      // الـ defineProperty عشان الـ key اللي اسمه ⁦__proto__⁩ يفضل بيانات، زي JSON.parse بالظبط
      Object.defineProperty(out, key, { value, enumerable: true, writable: true, configurable: true });
      this.skipWhitespace();
      const char = this.text[this.pos];
      if (char === "}") {
        this.pos++;
        return out;
      }
      if (char !== ",") this.fail("expected ',' or '}'");
      this.pos++;
    }
  }

  private parseString(): string {
    this.pos++;
    let out = "";
    let runStart = this.pos;
    for (;;) {
      if (this.pos >= this.text.length) this.fail("unterminated string");
      this.tick();
      const char = this.text[this.pos];
      if (char === '"') {
        out += this.text.slice(runStart, this.pos);
        this.pos++;
        return out;
      }
      if (char < " ") this.fail("raw control character in string");
      if (char !== "\\") {
        this.pos++;
        continue;
      }
      out += this.text.slice(runStart, this.pos);
      this.pos++;
      out += this.parseEscape();
      runStart = this.pos;
    }
  }

  private parseEscape(): string {
    const char = this.text[this.pos];
    if (char === "u") {
      const hex = this.text.slice(this.pos + 1, this.pos + 5);
      if (!/^[0-9a-fA-F]{4}$/.test(hex)) this.fail("bad unicode escape");
      this.pos += 5;
      return String.fromCharCode(parseInt(hex, 16));
    }
    if (char === undefined || !Object.hasOwn(SIMPLE_ESCAPES, char)) this.fail("bad escape");
    this.pos++;
    return SIMPLE_ESCAPES[char];
  }
}

export function normalizePathBrute(path: string, tick: () => void = () => {}): string {
  let current = path;
  for (;;) {
    let at = -1;
    for (let i = 0; i + 3 <= current.length; i++) {
      tick();
      if (current.startsWith("/..", i) && (i + 3 === current.length || current[i + 3] === "/")) {
        at = i;
        break;
      }
    }
    if (at === -1) return current === "" ? "/" : current;
    const parentStart = current.lastIndexOf("/", at - 1);
    current = at === 0
      ? current.slice(3)
      : current.slice(0, parentStart === -1 ? 0 : parentStart) + current.slice(at + 3);
    if (!current.startsWith("/")) current = "/" + current;
  }
}

const DEFAULT_PORTS = { http: 80, https: 443 } as const;
const HOST_NAME = /^[a-z0-9-]+(\.[a-z0-9-]+)*$/;
const IPV6_LITERAL = /^\[[0-9a-f:.]+\]$/;

export class UrlParseError extends Error {
  override readonly name = "UrlParseError";
}

// الـ subset المكتوب بصوت عالي قبل الكود:
// مدعوم: http و https المطلقين، host بالـ ASCII أو IPv6 بين أقواس، port، path، query، fragment
// مرفوض صراحةً: أي scheme تاني، userinfo، backslash، حروف غير ASCII في الـ host، relative
export function parseUrl(input: string): ParsedUrl {
  const schemeEnd = input.indexOf("://");
  if (schemeEnd === -1) throw new UrlParseError("not an absolute URL");
  const scheme = input.slice(0, schemeEnd).toLowerCase();
  if (scheme !== "http" && scheme !== "https") throw new UrlParseError(`unsupported scheme: ${scheme}`);

  // الترتيب مهم: الـ fragment الأول، بعده الـ query، وبعدهم الـ authority
  let rest = input.slice(schemeEnd + 3);
  let fragment = "";
  const hashAt = rest.indexOf("#");
  if (hashAt !== -1) {
    fragment = rest.length - hashAt > 1 ? rest.slice(hashAt) : "";
    rest = rest.slice(0, hashAt);
  }
  let query = "";
  const queryAt = rest.indexOf("?");
  if (queryAt !== -1) {
    query = rest.length - queryAt > 1 ? rest.slice(queryAt) : "";
    rest = rest.slice(0, queryAt);
  }
  if (rest.includes("\\")) throw new UrlParseError("backslash in URL");

  const pathAt = rest.indexOf("/");
  const authority = pathAt === -1 ? rest : rest.slice(0, pathAt);
  const rawPath = pathAt === -1 ? "/" : rest.slice(pathAt);
  if (authority.includes("@")) throw new UrlParseError("userinfo is not supported");

  const { host, port } = parseAuthority(authority, scheme);
  return { scheme, host, port, path: normalizePath(encodeSpaces(rawPath)), query: encodeSpaces(query), fragment: encodeSpaces(fragment) };
}

function parseAuthority(authority: string, scheme: "http" | "https"): { host: string; port: number | null } {
  // الـ IPv6 جواها : كتير، فنقطة الفصل هي آخر : بعد القوس المقفول
  const bracketEnd = authority.lastIndexOf("]");
  const colonAt = authority.indexOf(":", bracketEnd + 1);
  const host = (colonAt === -1 ? authority : authority.slice(0, colonAt)).toLowerCase();
  if (!HOST_NAME.test(host) && !IPV6_LITERAL.test(host)) throw new UrlParseError(`invalid host: ${host}`);
  if (colonAt === -1) return { host, port: null };

  const portText = authority.slice(colonAt + 1);
  if (portText === "") return { host, port: null };
  if (!/^\d+$/.test(portText)) throw new UrlParseError(`invalid port: ${portText}`);
  const port = Number(portText);
  if (port > 65535) throw new UrlParseError(`port out of range: ${port}`);
  return { host, port: port === DEFAULT_PORTS[scheme] ? null : port };
}

const encodeSpaces = (text: string): string => text.replaceAll(" ", "%20");

// لفة واحدة بـ stack: كل segment بيتلمس مرة واحدة
export function normalizePath(path: string, tick: () => void = () => {}): string {
  const output: string[] = [];
  const segments = path.split("/").slice(1);
  segments.forEach((segment, index) => {
    tick();
    const isLast = index === segments.length - 1;
    if (segment === ".") {
      if (isLast) output.push("");
    } else if (segment === "..") {
      output.pop();
      if (isLast) output.push("");
    } else {
      output.push(segment);
    }
  });
  return "/" + output.join("/");
}

الحل النهائي. اقطع بالترتيب الصح: الـ fragment الأول، وبعده الـ query، وبعده الـ authority، لأن ? و # ممكن يظهروا بعد الـ path عادي. الـ authority بتخلص عند أول /، والـ host هو كل اللي قبل الـ port، والـ IPv6 محتاج ندور على : بتاعة الـ port بعد ]. اتأكد من مدى الـ port. و ? و # الفاضيين كأنهم مش موجودين (أول differential run اكتشفها: http://a? الـ search بتاعه "" في WHATWG).

الـ differential تاني. 2,000 URL بـ seed من الـ subset متفقين مع new URL، والسلوكيات اللي في القايمة كلها طابقت: host كبير بيتصغّر، :443 بيتشال على https، /a/../orders بيبقى /orders، أقواس الـ IPv6 بتفضل، المسافة بتتعمل percent-encode، و port 99999 والـ relative مرفوضين. والـ host الدولي بيبقى punycode في new URL، وإحنا بنرفضه زي ما قلنا.

الـ security: اختلاف الـ parsers. الـ open redirects وفلاتر الـ SSRF بتتكسر لما الفحص والـ fetch يفسروا نفس الـ string بشكل مختلف. في الـ run، فلتر بـ split شايف shop.example بينما WHATWG شايف evil.example (بسبب backslash)، ومش واخد باله من 127.0.0.1 مكتوبة 2130706433 أو 0x7f.1 أو 127.1. فحص الـ prefix بيعدّي shop.example.evil.example. و startsWith('/') بيعدّي //evil.example وده origin تاني. شوف درس OWASP Top 10 في Node. في production استخدم new URL وقارن الـ .origin، وللـ SSRF كمان resolve الاسم وافحص الـ IP.

الغلطة الشائعة: تقطع الـ authority بعد @ بالـ split، فـ https://evil.example\@shop.example/ بيطلع host غلط.

فين هستخدمه في شغلي؟ أي endpoint بياخد redirect_to بعد الـ login، أو webhook URL بيحطه tenant وإنت بتعمله fetch من السيرفر. الكود الصح: new URL(next, base) ومقارنة الـ origin، وفي webhooks تعمل resolve وتتأكد إن الـ IP مش private. ده اللي بتدور عليه في code review لما تشوف startsWith على URL.

Common mistakes · غلطات شائعة

❌ A fresh iterator on every eviction 
// كل eviction بتبدأ من الأول وتلف على كل الـ holes
const oldest = this.map.keys().next().value as K;
this.map.delete(oldest);
✅ One iterator for the cache's lifetime 
// الـ iterator واقف مكانه وبيكمل من بعد آخر eviction
private readonly oldestKeys = this.map.keys();
this.map.delete(this.oldestKeys.next().value as K);
بالعامية

الـ ❌ شكلها O(1) والعداد بيقول O(1)، بس الوقت بيتضاعف x4 لأن كل iterator جديد بيبدأ من أول الـ table ويعدّي على كل الـ holes. عند سعة 100,000 ده فرق بين 6.4 ثانية و 15 ms. الـ ✅ سطر واحد زيادة: iterator بيفضل عايش، مش بيرجع لورا، وكل hole بيتعدّى عليها مرة واحدة.

❌ emit over the live array 
// الـ listener اللي بيشيل نفسه بيخلي اللي بعده يتنط
for (let i = 0; i < handlers.length; i++) handlers[i](payload);
✅ emit over a snapshot 
// النسخة ثابتة مهما الـ listeners غيّروا في الأصل
for (const [key, entry] of [...channel]) {
  if (entry.once) channel.delete(key);
  this.invoke(event, entry, payload);
}
بالعامية

في الـ ❌ لما الـ listener الأول يعمل off لنفسه، الـ array بتتزحزح والـ index اللي بعده بيطلع على العنصر التالت، فالتاني بيتنط. في الـ ✅ بنلف على نسخة، فأي إضافة أو شيل مش بيأثر على الدورة دي. والـ test فوق بيثبت الاتنين.

❌ No limit at all 
// الـ peak بيساوي n: 4000 task بيبدأوا مع بعض
await Promise.all(tasks.map((task) => task()));
✅ Workers on a shared index 
// الـ peak بيفضل عند الـ limit مهما كبر n
await runPool(tasks, { limit: 8 });
بالعامية

الـ ❌ قاس 4000 مع 4000 task: الـ downstream بيشوف 4000 طلب في نفس اللحظة. الـ ✅ بيحافظ على الحد من غير ما يبطّأ، لأن الـ workers بيملوا أي مكان يفضى على طول.

❌ Assigning untrusted keys 
// الـ ⁦__proto__⁩ هنا بيبدّل الـ prototype نفسه
for (const key of Object.keys(body)) out[key] = body[key];
✅ defineProperty or a null prototype 
// الـ key بيتسجل كبيانات، ومفيش setter يشتغل
Object.defineProperty(out, key, { value: body[key], enumerable: true, writable: true, configurable: true });
بالعامية

الـ ❌ بيطلع out.isAdmin === true و Object.keys(out) فاضية، فالـ logs شكلها سليم والـ authorization بايظة. الـ ✅ بيخلي __proto__ مجرد key زي أي key، أو تستخدم Object.create(null) ومفيش prototype أصلًا.

❌ A prefix check on the URL 
// الاتنين بيعدّوا: shop.example.evil.example و shop.example@evil.example
if (url.startsWith("https://shop.example")) redirect(url);
✅ Parse, then compare the origin 
// الـ origin هو الـ scheme والـ host والـ port بعد الـ parsing الحقيقي
const target = new URL(next, base);
if (target.origin === base) redirect(target.pathname + target.search);
بالعامية

الـ ❌ بيفحص حروف، مش host. الـ ✅ بيفحص الـ origin بعد ما parser واحد قياسي فسّر الـ URL، وبيرجّع path بس، فمفيش فرصة تروح لـ origin تاني.

Solution · الحل 
import { LruCache } from "./lru.ts";

type Bucket = { microTokens: number; refilledAt: number };
const MICRO_PER_TOKEN = 1_000_000;

export class BoundedTokenBucket {
  // الـ LRU هنا هو الحد الأقصى للذاكرة: أقدم key بيطلع لوحده
  private readonly buckets: LruCache<string, Bucket>;
  private readonly fullMicro: number;
  private readonly microPerMs: number;
  private readonly now: () => number;

  constructor(maxKeys: number, capacity: number, refillPerSecond: number, now: () => number) {
    this.buckets = new LruCache(maxKeys);
    this.fullMicro = capacity * MICRO_PER_TOKEN;
    this.microPerMs = (refillPerSecond * MICRO_PER_TOKEN) / 1000;
    this.now = now;
  }

  tryConsume(apiKey: string): boolean {
    const now = this.now();
    const bucket = this.buckets.get(apiKey) ?? { microTokens: this.fullMicro, refilledAt: now };
    const refilled = bucket.microTokens + Math.max(0, now - bucket.refilledAt) * this.microPerMs;
    bucket.microTokens = Math.min(this.fullMicro, refilled);
    bucket.refilledAt = now;
    const allowed = bucket.microTokens >= MICRO_PER_TOKEN;
    if (allowed) bucket.microTokens -= MICRO_PER_TOKEN;
    this.buckets.set(apiKey, bucket);
    return allowed;
  }

  get trackedKeys(): number {
    return this.buckets.size;
  }
}
التمن: الـ key اللي اتشال بسبب السعة بيرجع بـ bucket مليان، فـ attacker بيلف على keys كتير ممكن يطرد buckets ناس حقيقيين ويرجّعهم لـ full. لازم السقف يبقى أكبر من عدد الـ keys النشطة فعلًا. والـ test نجح: trackedKeys عمره ما عدّى 2.

Solution · الحل 
type Timer = ReturnType<typeof setTimeout>;

// الـ maxWait: حتى لو الدوشة مش بتهدى، لازم نحفظ كل maxWaitMs على الأقل
export function debounceMaxWait<A extends unknown[]>(fn: (...args: A) => void, waitMs: number, maxWaitMs: number) {
  let quietTimer: Timer | undefined;
  let maxTimer: Timer | undefined;
  let pending: A | undefined;

  const fire = () => {
    clearTimeout(quietTimer);
    clearTimeout(maxTimer);
    quietTimer = undefined;
    maxTimer = undefined;
    const args = pending as A;
    pending = undefined;
    fn(...args);
  };

  return (...args: A): void => {
    pending = args;
    clearTimeout(quietTimer);
    quietTimer = setTimeout(fire, waitMs);
    // الـ timer ده بيتظبط مرة واحدة لكل دفعة ومش بيتأجل
    maxTimer ??= setTimeout(fire, maxWaitMs);
  };
}
الـ ??= بيضمن إن الـ max timer بيتظبط أول نداء بس في الدفعة. الـ test: نداء كل 90 ms بـ wait 100 و maxWait 250، فالتنفيذ حصل عند 250 ms بالظبط بآخر قيمة، رغم إن الـ wait عمره ما انتهى.

Cheat sheet · الخلاصة

  • LRU: Map order with delete and re-set. Keep one iterator; a fresh keys() walks the holes (x4 in time, x2 in calls).
  • Follow-ups: TTL with an injected clock, single-flight getOrLoad, failed loads never cached.
  • Rate limiter: token bucket, lazy refill, integer micro-tokens, ceil on retryAfterMs, sweep full buckets, name Redis for many instances.
  • Emitter: generics over an event map, snapshot on emit, a stated throw policy, async rejections routed too.
  • Debounce keeps the latest after quiet; throttle gives one per interval. Test both on mock.timers.
  • Promise pool: N workers on a shared index, results by index. Peak counter plus deferreds as proof.
  • Deep clone: WeakMap registered before recursing, stated policy for classes and functions, structuredClone in production.
  • out[k] = v over untrusted JSON is prototype pollution: defineProperty or a null prototype.
  • JSON parser: recursive descent, one cursor, positions in errors, differential against JSON.parse, a depth cap.
  • URL parser: state the subset, refuse the rest, differential against URL. In production: new URL and compare origin.
