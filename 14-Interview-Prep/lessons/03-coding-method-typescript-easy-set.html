Why this matters · ليه ده مهم

English

The coding round is where a strong backend engineer can lose an offer in 45 minutes for reasons unrelated to their real skill: silence, a panic rewrite, a missed edge case, or a built-in that behaves differently from what they remember. The fix is a fixed routine, rehearsed until it survives stress. This lesson gives you that routine, runs it on one full problem, then drills the six core patterns in the form you will meet them: a timed prompt, the brute force first, the improved solution, tests, and measured growth. The same habits pay off at work: stating assumptions before coding, naming the slow part, and writing the test that catches the boundary bug.

Part 1 — The 45 minutes 🟢 Basicالجزء 1 — الـ 45 دقيقة

⏱ Timed prompt · 5 minutes On paper, split a 45-minute coding round into phases, in minutes, for one Medium problem, from the moment the call starts to the moment it ends. Then compare with the split below and circle where you differ.
على ورقة، قسّم coding round مدته 45 دقيقة لمراحل بالدقايق لمسألة Medium واحدة، من أول ما المكالمة تبدأ لحد ما تخلص. وبعدين قارن بالتقسيمة اللي تحت وعلّم على الأماكن اللي مختلف فيها.
English

The usual format is 45 minutes and one or two questions, and you are expected to talk while you solve. Treat it as a budget: about 3 minutes of introductions, 30 to 35 minutes on the problem, and 5 minutes for your questions. That adds up to 38–43 minutes, so the slack is 2 to 7 minutes for handoffs and overruns. With two questions, the problem block splits roughly 15 + 20 and every phase shrinks. Companies vary, so confirm the shape with the recruiter (lesson 01).

Inside the problem block, a workable split for one Medium is clarify 4, brute force 3, improve 4, code 14, verify 5, follow-up 5, which is the 35-minute upper bound. Two things stand out: coding gets less than half of the block, and verification has its own line so typing can't eat it.

A budget nobody enforces is a wish, so session.ts enforces it. It prints a checkpoint when each phase starts, warns one minute after a phase runs over and every minute after that, and reports what the overrun cost when you move on. It reads time only through setTimeout and Date.now, so mock.timers from node:test can replay a whole round in a fraction of a second. For real practice, session-cli.ts runs the same clock in real time and moves on each time you press Enter.

Four things get scored: communication, problem solving, code, and verification. Two of those four are about how you work, not the answer: a correct solution delivered in silence still leaves the interviewer with no evidence to write down.

// كل مرحلة ليها budget بالدقايق و cue بيفكّرك المفروض تعمل إيه
export type Phase = { name: string; budgetMin: number; cue: string };

export const ROUND_45: Phase[] = [
  { name: "intro", budgetMin: 3, cue: "30 seconds about you, then stop" },
  { name: "clarify", budgetMin: 4, cue: "questions, examples, edge cases" },
  { name: "brute force", budgetMin: 3, cue: "say it and its cost" },
  { name: "improve", budgetMin: 4, cue: "name the wasted work first" },
  { name: "code", budgetMin: 14, cue: "real names, small helpers" },
  { name: "verify", budgetMin: 5, cue: "hand trace, edge cases, complexity" },
  { name: "follow-up", budgetMin: 5, cue: "second question or an extension" },
  { name: "your questions", budgetMin: 5, cue: "on-call, reviews, growth" },
];

export type Session = { next(): boolean; stop(): void };

export function startSession(
  phases: readonly Phase[],
  print: (line: string) => void,
  minuteMs = 60_000,
): Session {
  const startedAt = Date.now();
  let phaseStartedAt = startedAt;
  let index = 0;
  let timer: ReturnType<typeof setTimeout> | undefined;

  const minutesSince = (from: number) => Math.round((Date.now() - from) / minuteMs);
  const stamp = () => String(minutesSince(startedAt)).padStart(2, "0") + "m";

  // أول تحذير بعد الـ budget بدقيقة، وبعدها تحذير كل دقيقة
  function nagAfter(waitMs: number, overBy: number): void {
    timer = setTimeout(() => {
      print(`${stamp()}   ! over budget on ${phases[index].name}: +${overBy}m, wrap up`);
      nagAfter(minuteMs, overBy + 1);
    }, waitMs);
  }

  function enter(): void {
    const phase = phases[index];
    print(`${stamp()} > ${phase.name} (${phase.budgetMin}m): ${phase.cue}`);
    phaseStartedAt = Date.now();
    nagAfter((phase.budgetMin + 1) * minuteMs, 1);
  }

  enter();
  return {
    // الدالة بترجع false لما المراحل تخلص
    next() {
      clearTimeout(timer);
      const spent = minutesSince(phaseStartedAt);
      const budget = phases[index].budgetMin;
      if (spent > budget) print(`${stamp()}   ${phases[index].name} took ${spent}m of ${budget}m`);
      index++;
      if (index === phases.length) {
        print(`${stamp()} done`);
        return false;
      }
      enter();
      return true;
    },
    stop() {
      clearTimeout(timer);
    },
  };
}

import { mock, test } from "node:test";
import assert from "node:assert/strict";
import { startSession, type Phase } from "./session.ts";

const phases: Phase[] = [
  { name: "a", budgetMin: 2, cue: "" },
  { name: "b", budgetMin: 1, cue: "" },
];

function run(steps: number[]): string[] {
  mock.timers.enable({ apis: ["setTimeout", "Date"] });
  const lines: string[] = [];
  const session = startSession(phases, (line) => lines.push(line));
  for (const minutes of steps) {
    for (let minute = 0; minute < minutes; minute++) mock.timers.tick(60_000);
    session.next();
  }
  session.stop();
  mock.timers.reset();
  return lines;
}

test("on budget: no warnings", () => {
  assert.equal(run([2, 1]).filter((l) => l.includes("!")).length, 0);
});

test("over budget: one warning per extra minute, then the spend", () => {
  const lines = run([4, 1]);
  assert.equal(lines.filter((l) => l.includes("over budget on a")).length, 2);

});

test("moving on early cancels the pending warning", () => {
  assert.ok(!run([1, 1]).some((l) => l.includes("!")));

بالعامية

الشكل المعتاد 45 دقيقة وسؤال أو اتنين، والمطلوب تتكلم وإنت بتحل. اتعامل معاها كـ budget: حوالي 3 دقايق تعارف، و30 لـ 35 دقيقة على المسألة، و5 دقايق لأسئلتك. المجموع 38–43 دقيقة، يعني اللي فاضل 2 لـ 7 دقايق بس للتنقلات والتأخير. لو سؤالين، الـ problem بيتقسم تقريبًا 15 + 20 وكل مرحلة بتصغر. والشركات بتختلف، فأكّد الشكل مع الـ recruiter (درس 01).

جوه الـ problem، تقسيمة شغالة لمسألة Medium واحدة: أسئلة 4، brute force 3، تحسين 4، كود 14، مراجعة 5، follow-up 5، وده أقصى 35 دقيقة. لاحظ حاجتين: الكود واخد أقل من نص الوقت، والمراجعة ليها سطر لوحدها عشان الكتابة متاكلهاش.

الـ budget اللي محدش بينفذه مجرد أمنية، فـ session.ts بينفذه. بيطبع checkpoint مع بداية كل مرحلة، وبيحذرك بعد دقيقة من انتهاء الـ budget وكل دقيقة بعدها، ولما تنتقل بيقولك التأخير كلفك كام. وهو بياخد الوقت من setTimeout وDate.now بس، فـ mock.timers بتاعة node:test تقدر تعيد مقابلة كاملة في أقل من ثانية. وللتمرين الحقيقي، session-cli.ts بيشغّل نفس الساعة في الوقت الفعلي وكل Enter بينقلك للمرحلة اللي بعدها.

فيه 4 حاجات بتتقيّم: التواصل، حل المشكلة، الكود، والـ verification. اتنين من الأربعة عن طريقة شغلك مش الإجابة: حل صح جاي في سكوت بيسيب الـ interviewer من غير أي دليل يكتبه.

فين هستخدمه في شغلي؟ نفس الـ timebox بتستخدمه في incident: 5 دقايق triage، 10 mitigate، وحد ماسك الساعة. والـ pattern نفسه (mock.timers مع وقت داخل من بره) هو اللي بتختبر بيه reminder job بتبعت notification بعد 24 ساعة، أو invoice بتتلغي بعد timeout، من غير ما الـ CI يستنى يوم.

⏱ Timed prompt · 25 minutes · Settlement match A payment provider settles one amount against an invoice. You get the invoice-line amounts in integer cents and the settlement amount. Return the indices of two lines that add up to it. Record yourself, talk the whole time, and stop at 25 minutes in whatever state you are in. This is the drill to do now.

English

Questions first. "Is there exactly one matching pair, or can there be none or several?" Return any one pair, or null if there is none. "Can amounts be negative, for example refunds?" Yes. "Can one line count twice?" No, two different lines, though two lines may hold the same amount. "Can the list be empty?" Yes, then null.

Examples and edges, out loud. [1200, 300, 450, 700] with 1000 gives [1, 3]. [500, 500] gives [0, 1]. [500] gives null. Integer cents means no floating-point comparison.

Brute force, out loud. "Check every pair: n(n−1)/2 comparisons, O(n²) time, O(1) extra space. At 100,000 lines that is about 5 × 10⁹ comparisons, which is too slow, so let me improve it."

Improve. "For each line I already know the exact partner I want: settlement minus this amount. The wasted work is scanning for it. A Map from amount to index answers that in O(1) on average, so the whole thing is O(n) time and O(n) space. I am trading memory for time, and refunds cost nothing extra because a hash doesn't care about order."

Code, trace, complexity. Trace [1200, 300, 450, 700] with 1000 by hand: 1200 wants −200, not seen, store it. 300 wants 700, not seen, store it. 450 wants 550, not seen, store it. 700 wants 300, seen at index 1, so return [1, 3]. Then say the complexity again, and back it with the op counts: the prediction was x4.00 per doubling for brute force and x2.00 for the map.

import { noTick, type Tick } from "./doubling.ts";

export type LinePair = [first: number, second: number];

// الحل الأول brute force: كل زوج مرة واحدة، ⁦O(n²)⁩ وقت و O(1) memory
export function matchBrute(amounts: readonly number[], settlement: number, tick: Tick = noTick): LinePair | null {
  for (let first = 0; first < amounts.length; first++) {
    for (let second = first + 1; second < amounts.length; second++) {
      tick();
      if (amounts[first] + amounts[second] === settlement) return [first, second];
    }
  }
  return null;
}

// الحل الأحسن: الـ Map بتجاوب "شفت المبلغ التاني قبل كده؟" في ⁦O(1)⁩
export function matchSettlement(amounts: readonly number[], settlement: number, tick: Tick = noTick): LinePair | null {
  const indexByAmount = new Map<number, number>();
  for (const [index, amount] of amounts.entries()) {
    tick();
    const partner = indexByAmount.get(settlement - amount);
    // لازم undefined صريحة: الـ partner ممكن يبقى index صفر
    if (partner !== undefined) return [partner, index];
    // التسجيل بعد الفحص عشان السطر ميتجمعش مع نفسه
    indexByAmount.set(amount, index);
  }
  return null;
}

English

First what panic produces. The brute force tries every start and walks forward until a SKU repeats: O(n²) time, O(n) extra space per start. The version below is that idea with one-letter names, and it has a bug: the inner loop runs with j <= a.length. At j === a.length, a[j] is undefined, it isn't in the set, and it gets counted as a new SKU, so every span that reaches the end is one too long. Plain --strict doesn't catch this because indexing an array returns string; noUncheckedIndexedAccess does.

Keep this four-point checklist on your paper and walk it before you say "done": empty input, one element, the boundary index (the first and last valid index, and what happens one past it), and loop termination (name the variable that moves and why it stops).

The clean version uses real names, two small helpers, and a half-open span: start is inside and end is outside, so the length is end - start and an empty span is simply start === end. The window only moves forward, so each SKU is handled once: O(n) time and O(n) space. Everything is stated before it is measured, and the measurement agrees: x4.00 per doubling against x2.00. The rule is simple: write it as if it were a PR, because in the interviewer's notes it is one.

// النطاق half-open: البداية جوه والنهاية بره، فالطول ⁦= end - start⁩
export type Span = { start: number; end: number };

// الـ brute force النضيف: كل نقطة بداية، ⁦O(n²)⁩
export function longestSpanBrute(skus: readonly string[], tick: Tick = noTick): Span {
  let best: Span = { start: 0, end: 0 };
  for (let start = 0; start < skus.length; start++) {
    const seen = new Set<string>();
    for (let cursor = start; cursor < skus.length && !seen.has(skus[cursor]); cursor++) {
      tick();
      seen.add(skus[cursor]);
      best = longerOf(best, { start, end: cursor + 1 });
    }
  }
  return best;
}

// الحل: الـ window بتتحرك لقدام بس، فكل عنصر بيتلمس مرة، ⁦O(n)⁩
export function longestSpanWithoutRepeat(skus: readonly string[], tick: Tick = noTick): Span {
  const lastIndexOf = new Map<string, number>();
  let best: Span = { start: 0, end: 0 };
  let windowStart = 0;

  for (const [index, sku] of skus.entries()) {
    tick();
    windowStart = startAfterRepeat(lastIndexOf.get(sku), windowStart);
    lastIndexOf.set(sku, index);
    best = longerOf(best, { start: windowStart, end: index + 1 });
  }
  return best;
}

// لازم Math.max: التكرار ممكن يكون قديم وبره الـ window الحالية
function startAfterRepeat(previousIndex: number | undefined, windowStart: number): number {
  if (previousIndex === undefined) return windowStart;
  return Math.max(windowStart, previousIndex + 1);
}

function longerOf(current: Span, candidate: Span): Span {
  return candidate.end - candidate.start > current.end - current.start ? candidate : current;
}

Sorting. sort() with no comparator converts to strings, so [10, 9, 1, 100] becomes [1, 10, 100, 9], and it mutates in place. Pass a comparator, and use toSorted when the caller's array must survive (Node 20+). Chain keys with ||.

Map and Set keep insertion order, which Object doesn't do for integer-like keys: they come first, ascending. That is why a counter or a dedupe belongs in a Map or Set, not an object.

Strings are UTF-16. "🧾INV".length is 5, not 4, because the emoji is two code units; slice and split("") can cut it in half. [...text] walks code points, and only Intl.Segmenter counts what a person sees as one character (the strings lesson has the details). Interview inputs are usually ASCII, but say so out loud as an assumption.

Costs. The table below is worth memorizing. The one that bites is using an array as a queue: shift() can move every remaining element, so draining with it is O(n²). The run below went from about 2 ms at 10,000 items to about 49 s at 320,000, while a moving head index stayed under 10 ms. Note the cliff between 10,000 and 20,000: small arrays look free (V8 can often trim the front of a small array in place; that is inferred from this behaviour, not read from V8's source, and it can change between versions), so a quick local test passes and the large input dies. function drainWithShift(n: number): number {
  const queue = Array.from({ length: n }, (_, i) => i);
  let sum = 0;
  while (queue.length > 0) sum += queue.shift()!;
  return sum;
}

function drainWithHead(n: number): number {
  const queue = Array.from({ length: n }, (_, i) => i);
  let head = 0;
  let sum = 0;
  while (head < queue.length) sum += queue[head++];
  return sum;
}

English

This part doesn't re-teach the patterns; the patterns lesson does that. Here you practice the interview form: name the signal, state the brute force and its cost, improve, test, and measure.

Drill 1, hash map. Signal: "seen before", "first duplicate". Brute force: compare each code with everything before it, O(n²). The scan answers a membership question, so a Set replaces it: O(n) time, O(n) space. Clarify what "first repeated" means: the code whose second occurrence is earliest, so A B B A gives B, not A.

Drill 2, two pointers. Signal: sorted input and a pair. Brute force: every pair, O(n²). With two ends, if the sum is below budget, pairing the low end with anything smaller than the high end only moves further away, so the low end can be dropped; the mirror holds above budget. Each step discards one element: O(n) time, O(1) space. Ties can go to any pair, so the tests compare the gap.

Drill 3, sliding window. Signal: consecutive items within a limit, on a sorted axis. Brute force: every order as a window start, O(n²) when orders are dense. The window keeps two indices that only move forward, so each order enters once and leaves once, at most 2n steps: O(n) time, O(1) space. Decide the boundary: the window is half-open, so an order exactly 5 minutes after the start is outside it.

The brute force doubles as a free oracle. When the fast version disagrees with it on random inputs from a fixed seed, you have found a bug before the interviewer did. In a live round you won't have time for that, but in practice it tells you whether your solution is really correct.

// الـ brute force: كل كوبون بيتقارن باللي قبله، ⁦O(n²)⁩
export function firstRepeatedBrute(codes: readonly string[], tick: Tick = noTick): string | null {
  for (let current = 1; current < codes.length; current++) {
    for (let earlier = 0; earlier < current; earlier++) {
      tick();
      if (codes[earlier] === codes[current]) return codes[current];
    }
  }
  return null;
}

  const seen = new Set<string>();
  for (const code of codes) {
    tick();
    if (seen.has(code)) return code;
    seen.add(code);
  }
  return null;
}

export type ClosestPair = { low: number; high: number; gap: number };

// الـ brute force: كل زوج، ⁦O(n²)⁩
export function closestPairBrute(costs: readonly number[], budget: number, tick: Tick = noTick): ClosestPair | null {
  let best: ClosestPair | null = null;
  for (let low = 0; low < costs.length; low++) {
    for (let high = low + 1; high < costs.length; high++) {
      tick();
      const gap = Math.abs(costs[low] + costs[high] - budget);
      if (best === null || gap < best.gap) best = { low, high, gap };
    }
  }
  return best;
}

// الحل: الـ input مترتب، فكل خطوة بتستبعد عنصر كامل، ⁦O(n)⁩
export function closestPair(costs: readonly number[], budget: number, tick: Tick = noTick): ClosestPair | null {
  let best: ClosestPair | null = null;
  let low = 0;
  let high = costs.length - 1;
  while (low < high) {
    tick();
    const sum = costs[low] + costs[high];
    const gap = Math.abs(sum - budget);
    if (best === null || gap < best.gap) best = { low, high, gap };
    if (sum === budget) break;
    // المجموع صغير: low مع أي حد أصغر من high هيبقى أبعد، فنسيب low
    if (sum < budget) low++;
    else high--;
  }
  return best;
}

export type Busiest = { startsAt: number; count: number };

// الـ brute force: كل order بداية window، ⁦O(n²)⁩ لو الكل قريب من بعض
export function busiestBrute(times: readonly number[], windowMs: number, tick: Tick = noTick): Busiest {
  let best: Busiest = { startsAt: 0, count: 0 };
  for (let start = 0; start < times.length; start++) {
    let count = 0;
    for (let cursor = start; cursor < times.length; cursor++) {
      tick();
      if (times[cursor] - times[start] >= windowMs) break;
      count++;
    }
    if (count > best.count) best = { startsAt: times[start], count };
  }
  return best;
}

// الحل: كل order بيدخل مرة ويخرج مرة، يعني 2n خطوة بالكتير
export function busiestWindow(times: readonly number[], windowMs: number, tick: Tick = noTick): Busiest {
  let best: Busiest = { startsAt: 0, count: 0 };
  let oldest = 0;
  for (let newest = 0; newest < times.length; newest++) {
    tick();
    // الـ window نصف مفتوحة: اللي على بعد windowMs بالظبط بره
    while (times[newest] - times[oldest] >= windowMs) {
      tick();
      oldest++;
    }
    const count = newest - oldest + 1;
    if (count > best.count) best = { startsAt: times[oldest], count };
  }
  return best;
}

بالعامية

الجزء ده مش بيشرح الـ patterns من الأول؛ درس الـ patterns عمل ده. هنا بتتمرن على شكل الـ interview: تسمّي الـ signal، تقول الـ brute force وتكلفته، تحسّن، تختبر، وتقيس.

تمرين 1، الـ hash map. الـ signal: "شفته قبل كده"، "أول تكرار". الـ brute force: قارن كل كود بكل اللي قبله، O(n²). الـ scan ده بيجاوب على سؤال وجود، فالـ Set بيحل محله: O(n) وقت و O(n) memory. وضّح معنى "أول تكرار": الكود اللي تاني ظهور ليه جه الأول، فـ A B B A بيدي B مش A.

تمرين 2، two pointers. الـ signal: input مترتب وزوج. الـ brute force: كل زوج، O(n²). بطرفين، لو المجموع أقل من الميزانية، أي زوج فيه الطرف الصغير مع حد أصغر من الطرف الكبير هيبعد أكتر، فنقدر نسيب الطرف الصغير؛ والعكس لو فوق الميزانية. كل خطوة بتستبعد عنصر: O(n) وقت و O(1) memory. والتعادل ممكن يروح لأي زوج، فالـ tests بتقارن الـ gap.

تمرين 3، sliding window. الـ signal: عناصر ورا بعض جوه حد، على محور مترتب. الـ brute force: كل order بداية window، O(n²) لو الـ orders متقاربة. الـ window ماسكة اتنين indices بيتحركوا لقدام بس، فكل order بيدخل مرة ويخرج مرة، 2n خطوة بالكتير: O(n) وقت و O(1) memory. وقرر الحد: الـ window half-open، فـ order جاي بعد 5 دقايق بالظبط من البداية يبقى بره.

الـ brute force كمان oracle ببلاش. لو النسخة السريعة اختلفت معاه على inputs عشوائية بـ seed ثابت، يبقى لقيت bug قبل الـ interviewer. في الجولة الحقيقية مش هيبقى عندك وقت لده، بس في التمرين بيقولك الحل صح فعلًا ولا لأ.

English

Background lives in sorting and binary search and graphs. Here is the interview form.

Drill 1, binary search. Signal: sorted input and "first position where". Brute force: scan, O(n). Keep a half-open search range with a written invariant: everything before low is before the date, and everything from high on is on or after it. The answer is where they meet, in the range 0 to n, so "none" needs no special case. O(log n) time. YYYY-MM-DD strings compare correctly as text; other date formats don't, so check.

Drill 2, BFS and DFS. Signal: "reachable", "connected". Brute force: loop over all routes until nothing new appears, O(V·E). BFS with a Set of visited nodes and a head-index queue visits each warehouse once and each route once: O(V + E). DFS with an explicit stack gives the same set in a different order. Don't reach for recursion on deep chains: here it overflowed near 4,500 levels (the depth depends on the frame size, and an earlier experiment with a different function got near 9,300), while the explicit stack handled 200,000.

Drill 3, sorting. Signal: intervals that may overlap. Brute force: compare every block with every block, restarting after each merge: at least O(n²). Sort by start with a numeric comparator, then sweep: each booking either extends the last block or starts a new one. O(n log n) from the sort, O(n) space. Ask whether touching windows (10–12 and 12–14) count as one block. Here they do, because a busy block has no gap. Copy the objects so you don't mutate the caller's data.

export function firstOnOrAfterScan(dates: readonly string[], target: string, tick: Tick = noTick): number {
  for (const [index, date] of dates.entries()) {
    tick();
    if (date >= target) return index;
  }
  return dates.length;
}

// الحل ⁦O(log n)⁩: اللي قبل low أصغر، واللي من high وطالع أكبر أو يساوي
export function firstOnOrAfter(dates: readonly string[], target: string, tick: Tick = noTick): number {
  let low = 0;
  let high = dates.length;
  while (low < high) {
    tick();
    const middle = low + Math.floor((high - low) / 2);
    if (dates[middle] < target) low = middle + 1;
    else high = middle;
  }
  return low;
}

export type Routes = ReadonlyMap<string, readonly string[]>;

// الـ brute force: لف على كل الـ routes لحد ما مفيش جديد، ⁦O(V·E)⁩
export function reachableByRelaxing(routes: Routes, from: string, tick: Tick = noTick): Set<string> {
  const reached = new Set([from]);
  let grew = true;
  while (grew) {
    grew = false;
    for (const [warehouse, targets] of routes) {
      for (const target of targets) {
        tick();
        if (reached.has(warehouse) && !reached.has(target)) {
          reached.add(target);
          grew = true;
        }
      }
    }
  }
  return reached;
}

// الحل BFS: مؤشر head بدل shift، ⁦O(V+E)⁩
export function reachableBfs(routes: Routes, from: string, tick: Tick = noTick): Set<string> {
  const seen = new Set([from]);
  const queue = [from];
  let head = 0;
  while (head < queue.length) {
    const warehouse = queue[head++];
    for (const target of routes.get(warehouse) ?? []) {
      tick();
      if (!seen.has(target)) {
        seen.add(target);
        queue.push(target);
      }
    }
  }
  return seen;
}

// نسخة DFS بـ stack صريح: نفس النتيجة وترتيب مختلف، ومفيش stack overflow
export function reachableDfs(routes: Routes, from: string, tick: Tick = noTick): Set<string> {
  const seen = new Set([from]);
  const stack = [from];
  while (stack.length > 0) {
    const warehouse = stack.pop()!;
    for (const target of routes.get(warehouse) ?? []) {
      tick();
      if (!seen.has(target)) {
        seen.add(target);
        stack.push(target);
      }
    }
  }
  return seen;
}

// نسخة recursive عشان نشوف الـ stack overflow بعينينا
export function reachableRecursive(routes: Routes, from: string, seen = new Set<string>()): Set<string> {
  seen.add(from);
  for (const target of routes.get(from) ?? []) {
    if (!seen.has(target)) reachableRecursive(routes, target, seen);
  }
  return seen;
}

export type Booking = { start: number; end: number };

const touches = (a: Booking, b: Booking) => a.start <= b.end && b.start <= a.end;

// الـ brute force: قارن كل block بكل block، وبعد أي دمج ابدأ تاني
export function mergeByRescanning(bookings: readonly Booking[], tick: Tick = noTick): Booking[] {
  const blocks = bookings.map((booking) => ({ ...booking }));
  for (let outer = 0; outer < blocks.length; outer++) {
    for (let inner = outer + 1; inner < blocks.length; inner++) {
      tick();
      if (touches(blocks[outer], blocks[inner])) {
        blocks[outer].start = Math.min(blocks[outer].start, blocks[inner].start);
        blocks[outer].end = Math.max(blocks[outer].end, blocks[inner].end);
        blocks.splice(inner, 1);
        inner = outer;
      }
    }
  }
  return blocks.toSorted((a, b) => a.start - b.start);
}

// الحل: رتّب بالبداية، وبعدها كل booking يا يكمّل الأخير يا يبدأ block جديد
export function mergeBookings(bookings: readonly Booking[], tick: Tick = noTick): Booking[] {
  const byStart = bookings.toSorted((a, b) => {
    tick();
    return a.start - b.start;
  });
  const merged: Booking[] = [];
  for (const booking of byStart) {
    tick();
    const last = merged.at(-1);
    if (last !== undefined && booking.start <= last.end) {
      // لازم Math.max: الـ booking ممكن يكون جوه اللي قبله بالكامل
      last.end = Math.max(last.end, booking.end);
    } else {
      merged.push({ ...booking });
    }
  }
  return merged;
}

export type Attempt = { id: string; status: "solved" | "revisit"; minutes: number };

// الأرقام دي من listings خارجية: راجعها على الموقع وعدّلها لو اتغيرت
export const LEVELS = [
  { prefix: "E", name: "Easy", total: 28 },
  { prefix: "M", name: "Medium", total: 101 },
  { prefix: "H", name: "Hard", total: 21 },
];

// القراءة بالاسم مش بالمكان، فأي عمود زيادة في الملف مش بيبوّظ حاجة
export function parseAttempts(csv: string): Attempt[] {
  const [headerLine, ...rows] = csv.trim().split(/\r?\n/);
  const header = headerLine.split(",").map((name) => name.trim());
  const column = (name: string) => {
    const at = header.indexOf(name);
    if (at === -1) throw new Error(`missing column: ${name}`);
    return at;
  };
  const [idAt, statusAt, minutesAt] = [column("id"), column("status"), column("minutes")];

  return rows.map((row, offset) => {
    const lineNumber = offset + 2;
    const cells = row.split(",").map((cell) => cell.trim());
    const [id, status, minutes] = [cells[idAt], cells[statusAt], Number(cells[minutesAt])];
    if (!LEVELS.some((level) => id?.startsWith(level.prefix))) throw new Error(`line ${lineNumber}: bad id "${id}"`);
    if (status !== "solved" && status !== "revisit") throw new Error(`line ${lineNumber}: bad status "${status}"`);
    if (!Number.isInteger(minutes) || minutes <= 0) throw new Error(`line ${lineNumber}: bad minutes "${cells[minutesAt]}"`);
    return { id, status, minutes };
  });
}

export function median(values: readonly number[]): number | null {
  if (values.length === 0) return null;
  const sorted = values.toSorted((a, b) => a - b);
  const middle = Math.floor(sorted.length / 2);
  return sorted.length % 2 === 1 ? sorted[middle] : (sorted[middle - 1] + sorted[middle]) / 2;
}

export type LevelRow = { name: string; solved: number; revisit: number; left: number; total: number; medianMinutes: number | null };

// آخر سطر لكل id هو الحالة الحالية، فالـ attempts القديمة بتفضل في الملف
export function summarize(attempts: readonly Attempt[]): LevelRow[] {
  const latest = new Map(attempts.map((attempt) => [attempt.id, attempt]));
  return LEVELS.map(({ prefix, name, total }) => {
    const current = [...latest.values()].filter((attempt) => attempt.id.startsWith(prefix));
    const solved = current.filter((attempt) => attempt.status === "solved").length;
    const revisit = current.length - solved;
    return { name, solved, revisit, left: total - current.length, total, medianMinutes: median(current.map((a) => a.minutes)) };
  });
}

export function formatTable(rows: readonly LevelRow[]): string {
  const head = "level    solved  revisit  left  total  median-min";
  const body = rows.map((row) =>
    [row.name.padEnd(8), String(row.solved).padStart(6), String(row.revisit).padStart(8), String(row.left).padStart(5), String(row.total).padStart(6), String(row.medianMinutes ?? "-").padStart(11)].join(" "),
  );
  return [head, ...body].join("\n");
}

    if (!seen.has(next)) { seen.add(next); queue.push(next); }
  }
}

// تمرين 1: أكبر مجموع مش بيعدّي الميزانية
export function bestWithinBudget(costs: readonly number[], budget: number): number | null {
  let best: number | null = null;
  let low = 0;
  let high = costs.length - 1;
  while (low < high) {
    const sum = costs[low] + costs[high];
    if (sum > budget) {
      high--;
      continue;
    }
    best = best === null ? sum : Math.max(best, sum);
    low++;
  }
  return best;
}

// البحثين شكلهم واحد والفرق علامة مقارنة بتتبعت من بره
function boundary(dates: readonly string[], goesRight: (date: string) => boolean): number {
  let low = 0;
  let high = dates.length;
  while (low < high) {
    const middle = low + Math.floor((high - low) / 2);
    if (goesRight(dates[middle])) low = middle + 1;
    else high = middle;
  }
  return low;
}

// تمرين 2: عدد الفواتير بين تاريخين، والاتنين داخلين
export function countBetween(dates: readonly string[], from: string, to: string): number {
  const first = boundary(dates, (date) => date < from);
  const afterLast = boundary(dates, (date) => date <= to);
  return Math.max(0, afterLast - first);
}
الـ Math.max بتغطي مدى معكوس. اتختبر على طرفين داخلين، مدى فاضي، مدى معكوس، و list فاضية.

import type { Routes } from "./warehouses.ts";

// تمرين 3: أقصر طريق بعدد النقلات، والـ BFS بيضمن إن أول وصول هو الأقصر
export function shortestRoute(routes: Routes, from: string, to: string): string[] | null {
  const cameFrom = new Map<string, string | null>([[from, null]]);
  const queue = [from];
  for (let head = 0; head < queue.length; head++) {
    const warehouse = queue[head];
    if (warehouse === to) return rebuild(cameFrom, to);
    for (const target of routes.get(warehouse) ?? []) {
      if (!cameFrom.has(target)) {
        cameFrom.set(target, warehouse);
        queue.push(target);
      }
    }
  }
  return null;
}

function rebuild(cameFrom: ReadonlyMap<string, string | null>, to: string): string[] {
  const path: string[] = [];
  for (let step: string | null | undefined = to; step != null; step = cameFrom.get(step)) path.push(step);
  return path.reverse();
}
