Why this matters · ليه ده مهم

English

Before anyone hears you explain a design, they read a page about you. That page has one job: earn the first call, and then give the interviewer good questions. Every line on it is a claim you can be asked about, so writing it well and writing it truthfully are the same task. In real terms this lesson gives you a CV, a LinkedIn and a GitHub that tell one consistent story, and a habit of keeping evidence as you work.

بالعامية

قبل ما أي حد يسمعك بتشرح design، بيقرأ صفحة عنك. الصفحة دي ليها شغلانة واحدة: تجيبلك أول مكالمة، وبعدين تدي الـ interviewer أسئلة كويسة. كل سطر فيها ادعاء ممكن تتسأل عنه، فإنك تكتبها كويس وتكتبها بصدق هما نفس المهمة. وعمليًا، الدرس ده هيطلع منه CV و LinkedIn و GitHub بيحكوا قصة واحدة متسقة، وعادة إنك تجمع أدلة وإنت بتشتغل.

  const first = b.split(/\s+/)[0] ?? "";
  return irregular.has(first) || /^[A-Z][a-z]+ed$/.test(first);

const dutyPhrase = /^(responsible for|worked (on|closely)|helped|assisted|involved in|participated in|attended|used)\b/i;

export type Report = { pages: number; bullets: number; noDigit: string[]; noVerb: string[]; duty: string[] };

export function lint(markdown: string): Report {
  const lines = markdown.split(/\r?\n/);
  // السطر الطويل بيتلف على كذا سطر في الورقة، والفاضي بياخد نص سطر
  const rendered = lines.reduce((n, l) => n + (l.trim() ? Math.ceil(l.length / CHARS_PER_LINE) : 0.5), 0);
  const bullets = lines.filter((l) => l.startsWith("- ")).map((l) => l.slice(2).trim());
  return {
    pages: Math.round((rendered / LINES_PER_PAGE) * 10) / 10,
    bullets: bullets.length,
    noDigit: bullets.filter((b) => !/\d/.test(b)),
    noVerb: bullets.filter((b) => !startsWithVerb(b)),
    duty: bullets.filter((b) => dutyPhrase.test(b)),
  };
}

الإجابة النموذجية. صفحة واحدة، واتنين بالكتير. الشغل الأحدث ياخد المساحة، فالدور الحالي فيه أغلب الـ bullets. الـ bullets بتقول أثر بأرقام، مش مهام: قارن "نزّلت p99 من 900ms لـ 140ms بإني شلت N+1 وضفت composite index" بـ "شغلت على الـ performance". وشيل أي حاجة مش مستاهلة سطرها: جملة الـ objective، والعنوان، وقايمة الكورسات، والهوايات، و"references available upon request".

cv-lint.ts بيقرأ CV بصيغة Markdown، ويقدّر عدد الصفحات من عدد السطور، ويعلّم على الـ bullets اللي مفيهاش رقم، واللي مش بادئة بفعل، واللي صيغتها مهام. وده heuristic تقريبي عن الشكل بس: مايقدرش يقول الرقم حقيقي ولا لأ، ولا القصة ماشية ولا لأ. والأرقام اللي في الأداة (50 سطر في الصفحة و95 حرف في السطر) تقريب لورقة A4 بخط 11، فعدّلها لو الشكل بتاعك مختلف.

Model answer. The formula is verb + what + impact. All twelve rewrites below come only from the fact sheet; the last two are second angles on stories 1 and 5, because one story can support more than one bullet.

The defence test. From the interviewer's side, every bullet is a question waiting to be asked. Each number has to survive four follow-ups: How was it measured? What was the baseline? What was your share? What else changed? If you can't answer them, the bullet isn't ready, however good it sounds.

Where honest numbers come from: dashboards, traces, the git log and ticket counts. If no number exists, you have three honest options and no others: measure it now, give an estimate and say how you made it, or say it wasn't measured. When there is genuinely no number, use scope instead: number of tenants, events a day, team size, or the before and after state. Mariam's tax e-invoice bullet has no number and stays that way. A strong brag document makes this easy, because you wrote the facts down when they happened.

defence.ts checks a sheet of bullets with their four answers and reports what is still blank, plus vague size words and "the team" as a share. A rough heuristic: it sees blanks, and can't tell whether an answer is true.

// الملف ده بيدوّر على أي skill في سطر Production ومفيش bullet بيسنده، ومقياس تقريبي برضه.
// للتشغيل: node stack-audit.ts fixtures/stack-padded.md fixtures/stack-clean.md
import { readFileSync } from "node:fs";

// الاسم في الـ skills line ممكن يختلف عن كتابته في الـ bullet
const aliases: Record<string, RegExp> = {
  "PostgreSQL": /\bpostgres(ql)?\b/i,
  "Node.js": /\bnode(\.js)?\b/i,
  "Redis Streams": /\bredis streams?\b/i,
};
const buzzwords = /^(microservices|blockchain|ai\/ml|agile|scrum|big data|cloud|synergy|problem solving|teamwork)$/i;

function tier(markdown: string, label: string): string[] {
  const line = markdown.split(/\r?\n/).find((l) => l.startsWith(`${label}:`)) ?? "";
  return line.slice(label.length + 1).split(",").map((s) => s.trim()).filter(Boolean);
}

export function audit(markdown: string) {
  const bullets = markdown.split(/\r?\n/).filter((l) => l.startsWith("- ")).join("\n");
  const supported = (skill: string) =>
    (aliases[skill] ?? new RegExp(`\\b${skill.replace(/[.+*?^$()[\]{}|\\/]/g, "\\$&")}\\b`, "i")).test(bullets);

  const production = tier(markdown, "Production");
  const familiar = tier(markdown, "Familiar");
  const all = [...production, ...familiar];
  return {
    production: production.length,
    // الـ Production اللي مالوش bullet هو السؤال اللي هتتزنق فيه
    unsupported: production.filter((s) => !supported(s) && !buzzwords.test(s)),
    buzzwords: all.filter((s) => buzzwords.test(s)),
    familiar: familiar.filter((s) => !buzzwords.test(s)),
  };
}

export function compare(cv: Position[], li: Position[]): string[] {
  const out: string[] = [];
  // المطابقة بالترتيب مش بالمسمى، لأن المسمى نفسه ممكن يكون هو اللي مختلف

type Check = { name: string; pass: (md: string) => boolean };

const section = (md: string, re: RegExp): string => {
  // بنقطع الـ README على عناوين ⁦##⁩ ونرجّع القطعة اللي عنوانها بيطابق
  const parts = md.split(/^## /m);

const intro = (md: string) => md.split(/^## /m)[0].split("\n").filter((l) => l && !l.startsWith("#") && !l.startsWith("!")).join(" ");

  { name: "what and why", pass: (md) => intro(md).split(/\s+/).length >= 15 && /\b(because|so|for|exists)\b/i.test(intro(md)) },

  { name: "architecture diagram", pass: (md) => /mermaid|!\[/.test(section(md, /architecture/i)) },

الإجابة النموذجية. الـ portfolio هو المشروع الجانبي منشور: live URL، والـ repo، والـ design docs. العمق بيكسب بسبب طريقة شغل الـ interviews: الـ interviewer يقدر يحفر 20 دقيقة في نظام حقيقي واحد ويفضل يلاقي قرارات و trade-offs وفشل، بينما 5 tutorials بيخلصوا في دقيقتين. اللي توريه: C4 container diagram، و ADRs، وتقرير load test من project/reports/، وفيديو demo دقيقتين.

1. A length rule 🟢 easy Add a rule to cv-lint.ts that flags any bullet longer than two rendered lines (190 characters at 95 per line). Run it on cv-strong.md.
ضيف قاعدة لـ cv-lint.ts بتعلّم على أي bullet أطول من سطرين على الورقة (190 حرف، 95 في السطر). وشغّلها على cv-strong.md.
Solution · الحل 
// الحل: قاعدة جديدة بتمسك الـ bullet اللي أطول من سطرين على الورقة.
// للتشغيل: node long-bullets.ts fixtures/cv-strong.md
import assert from "node:assert/strict";
import { readFileSync } from "node:fs";

// تقريبًا 95 حرف في السطر، زي cv-lint.ts، فسطرين يبقوا 190
const MAX_CHARS = 190;

export function tooLong(markdown: string): string[] {
  return markdown
    .split(/\r?\n/)
    .filter((l) => l.startsWith("- "))
    .map((l) => l.slice(2).trim())
    .filter((b) => b.length > MAX_CHARS);
}

assert.deepEqual(tooLong(`- Short bullet with 1 number.\n- ${"x".repeat(191)}`).length, 1);
assert.deepEqual(tooLong(`- ${"x".repeat(190)}`), []);

const path = process.argv[2] ?? "fixtures/cv-strong.md";
console.log(tooLong(readFileSync(path, "utf8")).length, "bullet(s) over", MAX_CHARS, "chars");
0 bullet(s) over 190 chars
الدالة بتطلّع الـ bullets وتفلتر الأطول من 190 حرف، والـ asserts بتثبّت الحد بالظبط: 191 بيتمسك و190 لأ. الناتج على الـ CV القوي 0، يعني كله في حدود السطرين.
2. Overlapping dates 🟡 medium Write overlaps(positions) for consistency.ts. Two positions overlap when the later one starts on or before the month the earlier one ends. Dates are YYYY-MM strings and present means still running. Test both an overlap and a clean sequence.
اكتب overlaps(positions) لـ consistency.ts. الدورين يتداخلوا لما اللي بعده يبدأ في نفس شهر نهاية الأول أو قبله. التواريخ YYYY-MM وكلمة present معناها لسه شغال. جرّب حالة فيها تداخل وحالة نضيفة.
Solution · الحل 
// الحل: بيدوّر على فترات متداخلة، زي وظيفتين ف نفس الشهر من غير ما يتقال.
// للتشغيل: node overlap.ts fixtures/cv.json
import assert from "node:assert/strict";
import { readFileSync } from "node:fs";
import type { Position } from "./consistency.ts";

// كلمة present بتتحول لتاريخ كبير عشان المقارنة تفضل نص عادي
const endOf = (p: Position) => (p.end === "present" ? "9999-12" : p.end);

export function overlaps(positions: Position[]): string[] {
  // التاريخ بصيغة YYYY-MM بيترتب صح كنص من غير parsing
  const sorted = [...positions].sort((a, b) => a.start.localeCompare(b.start));
  const out: string[] = [];
  for (let i = 1; i < sorted.length; i++) {
    const prev = sorted[i - 1];
    const cur = sorted[i];
    if (cur.start <= endOf(prev)) out.push(`${prev.title} overlaps ${cur.title} at ${cur.start}`);
  }
  return out;
}

const mk = (title: string, start: string, end: string): Position => ({ company: "OrderLane", title, start, end });

assert.deepEqual(overlaps([mk("A", "2021-10", "2023-08"), mk("B", "2023-09", "present")]), []);
assert.deepEqual(overlaps([mk("A", "2021-10", "2023-09"), mk("B", "2023-09", "present")]), ["A overlaps B at 2023-09"]);

const cv = JSON.parse(readFileSync(process.argv[2] ?? "fixtures/cv.json", "utf8")) as { positions: Position[] };
console.log(overlaps(cv.positions));
[]
صيغة YYYY-MM بتترتب صح كنص، فمفيش حاجة لـ parsing. كلمة present بتتحول لتاريخ كبير. الناتج على cv.json قايمة فاضية: مفيش تداخل.
3. Dead links in a README 🔴 hard Extend readme-lint.ts so it reports relative links whose target file doesn't exist. Keep external URLs out of scope.
كبّر readme-lint.ts بحيث يقول الروابط النسبية اللي الملف بتاعها مش موجود. والروابط الخارجية مش جزء من الفحص.
Solution · الحل 
// الحل: بيدوّر على الروابط النسبية في الـ README اللي الملف بتاعها مش موجود.
// للتشغيل: node dead-links.ts fixtures/readme-strong.md
import assert from "node:assert/strict";
import { existsSync, readFileSync } from "node:fs";
import { dirname, join } from "node:path";

export function deadLinks(markdown: string, baseDir: string): string[] {
  const targets = [...markdown.matchAll(/\]\(([^)#\s]+)(#[^)]*)?\)/g)].map((m) => m[1]);
  // الروابط الخارجية خارج الفحص، إحنا بنفحص الملفات بس
  const local = targets.filter((t) => !/^[a-z]+:/i.test(t));
  return local.filter((t) => !existsSync(join(baseDir, t)));
}

const here = import.meta.dirname;
assert.deepEqual(deadLinks("[ok](fixtures/cv.json)", here), []);
assert.deepEqual(deadLinks("[x](fixtures/nope.md)", here), ["fixtures/nope.md"]);
assert.deepEqual(deadLinks("[ext](https://example.com/nope.md)", here), []);

const path = process.argv[2] ?? "fixtures/readme-strong.md";
console.log(deadLinks(readFileSync(path, "utf8"), dirname(path)));
[
  'docs/screenshot.png',
  'adr/0001-fastify-over-nest.md',
  'adr/0007-redis-streams.md'
]
بيطلّع الروابط من الـ Markdown، يشيل الخارجية (اللي بتبدأ بـ scheme زي https:)، ويشوف الملف موجود ولا لأ. الناتج على الـ fixture تلات روابط مكسورة، وده طبيعي لأن orderdesk متخيل وملفاته مش موجودة. على مشروعك الحقيقي، أي سطر هنا هو لينك هيضايق reviewer.

Cheat sheet · الخلاصة

  • One page, two at most. Recent work gets the space. Impact with numbers, not duties.
  • Every bullet: verb + what + impact, and a story you can defend for 5 minutes.
  • The defence test: how measured, what baseline, your share, what else changed?
  • Numbers come from dashboards, traces, git log, tickets. No number: measure it, estimate and say how, or say it wasn't measured. Never invent one.
  • With no number, use scope (tenants, events a day, team size) or the before and after state.
  • Stack in two tiers: Production (shipped and ran) and Familiar (5 minutes of talk). Buzzwords out.
  • Match the JD's words where they are true; never add a tool you can't discuss.
  • LinkedIn dates and titles identical to the CV. Headline: role + domain + proof.
  • Recommendations: ask people who saw the work, give them something specific.
  • Profile README: public repo named after your username, non-empty README in the root. Pin up to six items combined.
  • Pin the side project, patterns repo and MCP server, not course clones. README standard: project/README.md rule 4.
  • One deep system beats five shallow ones. Not live yet? An honest status line.

  • اختبار الدفاع: اتقاس إزاي، الـ baseline كام، نصيبك إيه، إيه اللي اتغير كمان؟
  • الأرقام من الـ dashboards والـ traces والـ git log والـ tickets. مفيش رقم؟ قيسه، أو قدّره وقول إزاي، أو قول إنه ما اتقاسش. وأوعى تألف.
