Why this matters · ليه ده مهم

English

You can solve a problem alone and still fail it with someone watching. Talking while you think, keeping time, and taking a hard follow-up are skills, and a mock is the only place you get to practise them without losing an opportunity. The rest of this section builds the knowledge. This lesson builds the loop that shows you whether the knowledge comes out under pressure.

A mock you don't review is only a rehearsal. So the point here is to turn every mock into data: a recording, three written lines, scores per dimension, and a concrete drill for next week. Even if you never change jobs, this is the fastest way to find your own gaps.

بالعامية

ممكن تحل المسألة وإنت لوحدك كويس جدًا، وتقع فيها لما حد يبقى قاعد بيتفرج عليك. الكلام وإنت بتفكر، ومسك الوقت، والرد على follow-up صعب، دي مهارات في حد ذاتها، والـ mock هو المكان الوحيد اللي تتمرن فيه عليها من غير ما تخسر فرصة حقيقية. باقي القسم بيبني المعرفة، والدرس ده بيبني الـ loop اللي بيوريك المعرفة دي بتطلع تحت الضغط ولا لأ.

الـ mock اللي مش بتراجعه مجرد بروفة. فالهدف هنا إن كل mock يتحوّل لـ data: تسجيل، 3 سطور مكتوبة، درجات لكل dimension، وتمرين محدد للأسبوع الجاي. وحتى لو عمرك ما هتغيّر شغلك، دي أسرع طريقة تكتشف بيها الفجوات بتاعتك.

Part 1 — Where mocks come from 🟡 Intermediateالجزء 1 — تلاقي mocks منين

English

⏱ Timed prompt, 5 minutes. On paper, name who will interview you in the next month: one senior colleague, two peers and one platform. Next to each name, write the sentence you will use to ask about recording. Stop at 5 minutes.

Model solution. There are four kinds of source, and each is good at something different.

  • A senior colleague. The best feedback you can get, and the scarcest. Save this hour for system design and for mocks near the end of your preparation.
  • Peers. Cheap and repeatable. Swap roles: when you interview someone else you learn what a confusing answer feels like from the other side.
  • interviewing.io. Mocks with practising engineers. Its public replay library is the page the README links as /recordings, which now redirects to /mocks (308, observed 2026-11-09). The site says the replays are shared with permission from both participants.
  • Pramp, now Aced. Pramp's own page says that as of July 2024 all new sessions are hosted on Aced Practice. Exponent has also become Aced: tryexponent.com redirects to aced.io with a 301, and its homepage says "formerly Exponent" (observed 2026-11-09). It offers peer-to-peer mocks and an AI interviewer.

Prices change, so check each site yourself rather than trusting a number in a lesson. The rule that doesn't change is consent: ask before recording, and if the other person declines, record only your own voice. Laws on recording differ between countries, and asking first means you never have to work out which one applies.

The naive plan is one friend doing all 18 mocks. It looks simple and it fails: 18 hours is a lot to ask of one person, and one interviewer means one set of habits. The plan below spreads the slots and makes the recording mode explicit. Complexity is O(targets × sources), which doesn't matter at this size, so it stays a first-fit loop.

// تخطيط الـ mocks: مين هيعمل معايا إيه، والتسجيل هيبقى إزاي
import { resolve } from "node:path";

export type Kind = "design" | "coding" | "behavioral";
export type Consent = "yes" | "self-only" | "not-asked";

export interface Source {
  name: string;
  kinds: Kind[];
  slots: number;
  consent: Consent;
}

export interface Slot {
  kind: Kind;
  source: string;
  recording: string;
}

// القاعدة: مفيش موافقة صريحة يبقى مفيش تسجيل لصوت الطرف التاني
export function recordingMode(consent: Consent): string {
  if (consent === "yes") return "both voices";
  if (consent === "self-only") return "my voice only";
  return "ASK FIRST, nothing recorded yet";
}

// التعقيد ⁦O(targets * sources)⁩: أول مصدر فاضي بيغطي النوع، والرقم هنا صغير
export function planMocks(sources: Source[], targets: Record<Kind, number>) {
  const left = new Map(sources.map((s) => [s.name, s.slots]));
  const slots: Slot[] = [];
  const missing: Record<Kind, number> = { design: 0, coding: 0, behavioral: 0 };
  for (const kind of ["design", "behavioral", "coding"] as const) {
    for (let i = 0; i < targets[kind]; i++) {
      const src = sources.find((s) => s.kinds.includes(kind) && (left.get(s.name) ?? 0) > 0);
      if (!src) {
        missing[kind]++;
        continue;
      }
      left.set(src.name, (left.get(src.name) ?? 0) - 1);
      slots.push({ kind, source: src.name, recording: recordingMode(src.consent) });
    }
  }
  return { slots, missing };
}

الحل النموذجي. عندك 4 أنواع مصادر، وكل نوع شاطر في حاجة:

الأسعار بتتغير، فشوفها بنفسك على كل موقع ومتصدقش رقم مكتوب في درس. اللي مبيتغيرش هو الموافقة: اسأل قبل ما تسجّل، ولو الطرف التاني رفض، سجّل صوتك إنت بس. قوانين التسجيل بتختلف من بلد لبلد، ولما تسأل الأول مش هتحتاج أصلًا تعرف أنهي قانون بينطبق.

الخطة الساذجة هي صاحب واحد يعمل الـ 18 mock كلهم. شكلها بسيط بس بتفشل: 18 ساعة كتير أوي تطلبهم من شخص واحد، و interviewer واحد معناه نفس العادات كل مرة. الخطة في الكود بتوزّع الـ slots وبتخلّي طريقة التسجيل واضحة. الـ complexity هي O(targets × sources)، وده مش فارق في الحجم ده، فسيبناها loop بسيط بياخد أول مصدر فاضي.

فين هستخدمه في شغلي؟ زميلك السنيور اللي بيراجع الـ PRs بتاعتك في الـ payments service: اطلب منه ساعة واحدة كل أسبوعين، و mock system design على حاجة زي webhook ingestion. الجملة: "ممكن أسجّل صوتي بس عشان أراجع نفسي بعدين؟". ولو وافق يتسجّل هو كمان، يبقى أحسن. وفي نفس الوقت، peer من فريق تاني تعملوا مع بعض coding mocks بالدور كل أسبوع.

Part 2 — A protocol a friend can run 🟡 Intermediateالجزء 2 — بروتوكول ينفع صاحبك يشغّله

English

⏱ Timed prompt, 10 minutes (the drill for this session). Print one card from the code below. Set a timer, start your recording, and do the first 10 minutes alone, out loud: requirements and estimation for a design card, or questions and a brute force for a coding card. Then stop and listen to the first minute back.

Model solution. A friend who isn't a Senior can still interview you if they have a card. The session is 45 minutes plus 15 for feedback. The card holds four things: a prompt to read word for word, two follow-ups, the rules, and a rubric. The rules are what make it a real mock: don't help early, ask "why that?" after every choice, keep the clock out loud, and write down the minute of anything worth raising.

The brute force is Math.random(): it picks a case, but nobody can reproduce the card. With a seed, your friend prints the same card you agreed on, and you can repeat the same case a month later and compare. The cases come from your own list, written in your own words, not from a published question bank. Picking a case is O(cases) and it doesn't need to be better than that.

  kind: Kind;
  prompt: string;
  followUps: string[];
}

export interface Card {
  seed: number;
  kind: Kind;
  caseId: string;

  followUps: string[];

// ❌ أول نسخة: Math.random مبتتعادش، فمحدش يقدر يطلّع نفس الكارت تاني

// ✅ الـ mulberry32 خوارزمية PRNG صغيرة: نفس الـ seed يدي نفس التسلسل
function prng(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

const RUBRICS: Record<Kind, string[]> = {
  coding: ["communication", "problem solving", "code", "verification"],
  design: ["requirements", "estimation", "API and data", "high level", "deep dive", "trade-offs", "communication"],
  behavioral: ["scope", "ownership", "self-awareness", "evidence"],
};

const CLOCKS: Record<Kind, string[]> = {

  design: ["00:00 requirements", "05:00 estimation", "10:00 high level + API", "20:00 deep dive", "35:00 trade-offs + follow-ups", "45:00 end, 15 min feedback"],
  behavioral: ["00:00 story one", "10:00 story two", "20:00 story three", "30:00 push with follow-ups", "45:00 end, 15 min feedback"],
};

export const INTERVIEWER_RULES = [
  "Read the prompt once, word for word. Do not explain it unless asked.",
  "No help for 15 minutes. After that, one hint only if stuck 3 minutes or more.",
  "Ask 'why that?' after every choice.",
  "Keep the clock. Say the time out loud at each checkpoint.",

export function buildCard(all: Case[], opts: { seed: number; kind: Kind; skip?: string[] }): Card {
  const skip = new Set(opts.skip ?? []);
  const pool = all.filter((c) => c.kind === opts.kind && !skip.has(c.id));
  if (pool.length === 0) throw new Error(`no ${opts.kind} case left after skipping ${[...skip].join(",") || "nothing"}`);
  const next = prng(opts.seed);
  const chosen = pool[Math.floor(next() * pool.length)];
  // ملحوظة: بنخلط نسخة من الـ follow-ups بـ Fisher-Yates ونفضّل اتنين بس
  const fu = [...chosen.followUps];
  for (let i = fu.length - 1; i > 0; i--) {
    const j = Math.floor(next() * (i + 1));
    [fu[i], fu[j]] = [fu[j], fu[i]];
  }
  return { seed: opts.seed, kind: opts.kind, caseId: chosen.id, prompt: chosen.prompt, followUps: fu.slice(0, 2), rubric: RUBRICS[opts.kind], clock: CLOCKS[opts.kind] };
}

export function renderCard(c: Card): string {
  return [
    `MOCK CARD seed=${c.seed} kind=${c.kind} case=${c.caseId}`,
    "",
    "Read this once, word for word:",
    `  ${c.prompt}`,
    "",
    "Follow-ups (ask after the main answer):",
    ...c.followUps.map((q, i) => `  ${i + 1}. ${q}`),
    "",
    "Rules for you, the interviewer:",
    ...INTERVIEWER_RULES.map((r) => `  - ${r}`),
    "",
    "Clock:",
    ...c.clock.map((t) => `  ${t}`),
    "",
    "Score each 1 to 4, and give the minute of one example for each:",
    ...c.rubric.map((r) => `  [ ] ${r}`),
  ].join("\n");
}

English

⏱ Timed prompt, 10 minutes. Read transcript A below as if it were your own recording. By hand, write three lines: where I went silent, where I assumed without asking, and what non-functional requirement I forgot. Only then run the tool.

Model solution. Both transcripts are fictional, and the format is the one most transcription tools can export: one segment per line, with start, end and speaker. review.ts does four things: it finds silences over 20 seconds, counts clarifying questions, counts assumptions said without a question before them, and checks whether non-functional words appear in the first 10 minutes. It is a rough heuristic built on word matching, so treat the numbers as pointers to moments to listen to, not as a grade.

Silences are the only part with a real algorithm. The brute force walks every second of the recording and scans every segment: O(S × n), where S is the length in seconds. The final version sorts by start and sweeps once, tracking the furthest end seen so far, which also handles the interviewer talking over you: O(n log n) in the worst case. Recordings grow together with segments, so doubling n doubles S too, and the brute force goes x4 per doubling. The sweep goes x2 here because the input is two already-sorted tracks and the sort is close to linear on that.

export interface Segment {
  start: number;
  end: number;
  speaker: "C" | "I";
  text: string;
}

export interface Silence {
  from: number;
  to: number;
  after: string;
}

type Tick = () => void;

const LINE = /^(\d\d):(\d\d)-(\d\d):(\d\d) ([CI]) (.+)$/;

export function parseTranscript(raw: string): Segment[] {
  return raw
    .split(/\r?\n/)
    .filter((l) => l.trim() !== "")
    .map((l, i) => {
      const m = LINE.exec(l);
      if (!m) throw new Error(`line ${i + 1} is not 'mm:ss-mm:ss C|I text': ${l}`);
      return { start: +m[1] * 60 + +m[2], end: +m[3] * 60 + +m[4], speaker: m[5] as "C" | "I", text: m[6] };
    });
}

// الـ ⁦brute force: O(S * n)⁩ حيث S عدد ثواني التسجيل. كل ثانية بنلف على كل الـ segments
export function silencesBrute(segs: Segment[], over: number, tick: Tick = () => {}): Silence[] {
  const lastEnd = Math.max(0, ...segs.map((s) => s.end));
  const out: Silence[] = [];
  let quietFrom = -1;
  for (let sec = 0; sec <= lastEnd; sec++) {
    let spoken = false;
    for (const s of segs) {
      tick();
      if (s.start <= sec && sec < s.end) spoken = true;
    }
    if (!spoken && quietFrom === -1) quietFrom = sec;
    if (spoken && quietFrom !== -1) {
      if (sec - quietFrom > over) out.push({ from: quietFrom, to: sec, after: "" });
      quietFrom = -1;
    }
  }
  return out;
}

// الحل: ⁦O(n log n)⁩ ترتيب + مشي واحد. الـ maxEnd بيغطي لو حد قاطع التاني
export function silences(segs: Segment[], over: number, tick: Tick = () => {}): Silence[] {
  const sorted = [...segs].sort((a, b) => {
    tick();
    return a.start - b.start;
  });
  const out: Silence[] = [];
  let maxEnd = sorted.length ? sorted[0].end : 0;
  let last = sorted.length ? sorted[0] : undefined;
  for (const s of sorted.slice(1)) {
    tick();
    if (s.start - maxEnd > over) out.push({ from: maxEnd, to: s.start, after: last?.text ?? "" });
    if (s.end >= maxEnd) {
      maxEnd = s.end;
      last = s;
    }
  }
  return out;
}

const ASSUME = /\b(i'll assume|i assume|assuming|let's say|probably|i guess|must be)\b/i;

// تحذير: الكلام ده بيشم كلمات، فـ "ms" لوحدها ممكن تعدّي من غير ما تكون بتتكلم عن latency
export const NFR: Record<string, RegExp> = {
  latency: /\b(latency|p9\d|ms|milliseconds?|response time|on time|late)\b/i,
  volume: /\b(qps|rps|per second|per day|per month|a month|throughput|volume|traffic|peaks?)\b/i,
  availability: /\b(availability|uptime|down|sla|slo|outages?)\b/i,
  durability: /\b(durab\w+|lost|lose|retention|retr(y|ies)|dedupe|duplicates?|consisten\w+|at-least-once)\b/i,
  cost: /\b(cost|budget|expensive|cheap\w*|burn money)\b/i,
};

export interface Report {
  durationEnd: number;
  segments: number;
  silences: Silence[];
  clarifying: number;
  assumedUnasked: Segment[];
  nfrFound: string[];
  nfrMissing: string[];
}

const TEN_MIN = 600;

export function review(segs: Segment[]): Report {
  const cand = segs.filter((s) => s.speaker === "C");
  const firstTen = cand.filter((s) => s.start < TEN_MIN);
  const isQ = (s: Segment) => s.text.includes("?");
  const clarifying = firstTen.filter(isQ).length;
  const assumedUnasked = cand.filter((s) => {
    if (isQ(s) || !ASSUME.test(s.text)) return false;
    // افتراض "من غير سؤال⁦" =⁩ مفيش سؤال من الـ candidate في الـ 30 ثانية اللي قبله
    return !cand.some((q) => isQ(q) && q.start < s.start && s.start - q.end <= 30);
  });
  const text = firstTen.map((s) => s.text).join(" ");
  const nfrFound = Object.keys(NFR).filter((k) => NFR[k].test(text));
  const nfrMissing = Object.keys(NFR).filter((k) => !nfrFound.includes(k));
  return {
    durationEnd: Math.max(0, ...segs.map((s) => s.end)),
    segments: segs.length,
    silences: silences(segs, 20),
    clarifying,
    assumedUnasked,
    nfrFound,
    nfrMissing,
  };
}

const mmss = (t: number) => `${String(Math.floor(t / 60)).padStart(2, "0")}:${String(t % 60).padStart(2, "0")}`;
const clip = (t: string) => (t.length > 48 ? t.slice(0, 45) + "..." : t);

export function render(name: string, r: Report): string {
  return [
    `=== ${name}: ${r.segments} segments, ends at ${mmss(r.durationEnd)}`,
    `silences over 20 s: ${r.silences.length}`,
    ...r.silences.map((s) => `  ${mmss(s.from)} -> ${mmss(s.to)} (${s.to - s.from} s) after: "${clip(s.after)}"`),
    `clarifying questions in the first 10 min: ${r.clarifying}`,
    `assumptions said without asking: ${r.assumedUnasked.length}`,
    ...r.assumedUnasked.map((s) => `  ${mmss(s.start)} "${clip(s.text)}"`),
    `NFR families in the first 10 min: ${r.nfrFound.join(", ") || "NONE"}`,
    `missing: ${r.nfrMissing.join(", ") || "none"}`,
  ].join("\n");
}

English

⏱ Timed prompt, 25 minutes. Your friend reads card C1 (below). Charges arrive in time order as { customerId, cents, at }; return the index of every charge that repeats the same customer and amount within W seconds of an earlier one. Ask your questions, say a brute force out loud, then improve it. This drill is scheduled in Try it yourself: don't read the solution until you've done it.

Model solution. Questions first: is the input sorted by time, what if two charges share a timestamp, is the boundary inclusive? Then the brute force, which is O(n²) time and O(1) extra space: for each charge, scan all earlier charges. Then the improvement: a map from customerId:cents to the last time seen, O(n) time and O(k) space, where k is the number of distinct pairs. Only the most recent earlier charge matters, because input is in time order.

The README asks for at least five coding mocks with feedback, and "with feedback" is the part people skip. Use the four dimensions scored in lesson 03: communication, problem solving, code, verification. Every item needs a score from 1 to 4, and every comment needs a minute and a next step. feedback.ts enforces that shape.

Taking criticism without defending. Four steps: don't explain, write it down; ask for the minute if it's missing; repeat it back in your own words; decide tomorrow what to change. The moment you explain why you did something, your interviewer stops telling you the truth next time.

// مسألة الـ mock: كشف الـ charge المكرر لنفس العميل بنفس المبلغ خلال نافذة W ثانية
export interface Charge {
  customerId: string;
  cents: number;
  at: number;
}

type Tick = () => void;

function assertSorted(charges: Charge[]): void {
  for (let i = 1; i < charges.length; i++) {
    if (charges[i].at < charges[i - 1].at) throw new RangeError(`charges must be in time order, broken at index ${i}`);
  }
}

// الـ ⁦brute force: O(n^2)⁩ وقت، ⁦O(1)⁩ مساحة زيادة
export function duplicatesBrute(charges: Charge[], windowSec: number, tick: Tick = () => {}): number[] {
  assertSorted(charges);
  const out: number[] = [];
  for (let i = 0; i < charges.length; i++) {
    for (let j = 0; j < i; j++) {
      tick();
      const sameCharge = charges[j].customerId === charges[i].customerId && charges[j].cents === charges[i].cents;
      if (sameCharge && charges[i].at - charges[j].at <= windowSec) {
        out.push(i);
        break;
      }
    }
  }
  return out;
}

// الحل: ⁦O(n)⁩ وقت، ⁦O(k)⁩ مساحة حيث k عدد الأزواج (عميل، مبلغ) المختلفة
export function duplicates(charges: Charge[], windowSec: number, tick: Tick = () => {}): number[] {
  assertSorted(charges);
  const lastSeen = new Map<string, number>();
  const out: number[] = [];
  charges.forEach((charge, i) => {
    tick();
    const key = `${charge.customerId}:${charge.cents}`;
    const previous = lastSeen.get(key);
    if (previous !== undefined && charge.at - previous <= windowSec) out.push(i);
    lastSeen.set(key, charge.at);
  });
  return out;
}

const VAGUE = /\b(good job|nice work|well done|looks? (good|fine)|be more confident|communicate better|improve communication)\b/i;

export function lintFeedback(form: Feedback): string[] {
  const problems: string[] = [];
  for (const d of DIMENSIONS) {
    const s = form.scores[d];
    if (s === undefined) problems.push(`${d}: no score`);
    else if (!Number.isInteger(s) || s < 1 || s > 4) problems.push(`${d}: score must be 1 to 4, got ${s}`);
  }
  if (form.moments.length < 2) problems.push(`only ${form.moments.length} moment(s) with a minute, need at least 2`);
  form.moments.forEach((m, i) => {
    if (!/^\d\d:\d\d$/.test(m.at)) problems.push(`moment ${i + 1}: "${m.at}" is not mm:ss`);
    if (m.doNext.trim() === "") problems.push(`moment ${i + 1}: says what happened but not what to do`);
    if (VAGUE.test(m.what)) problems.push(`moment ${i + 1}: vague wording`);
  });
  if (VAGUE.test(form.summary)) problems.push(`summary is vague: "${form.summary}"`);
  return problems;
}

The real signal is the slope over all ten mocks, read together with the mean of the last three for "weakest now". export interface Mock {
  n: number;
  caseName: string;

export function parseLog(csv: string): Mock[] {
  const [header, ...rows] = csv.trim().split(/\r?\n/);
  const cols = header.split(",");
  return rows.map((row, r) => {
    const cells = row.split(",");
    if (cells.length !== cols.length) throw new Error(`row ${r + 2}: expected ${cols.length} cells, got ${cells.length}`);
    const scores: Record<string, number> = {};
    cols.slice(2).forEach((c, i) => {
      const v = Number(cells[i + 2]);
      if (!Number.isInteger(v) || v < 1 || v > 4) throw new Error(`row ${r + 2}: ${c} must be 1 to 4, got "${cells[i + 2]}"`);
      scores[c] = v;
    });
    return { n: Number(cells[0]), caseName: cells[1], scores };
  });
}

// الميل بالمربعات الصغرى: مين بيتحسن كام درجة لكل mock
export function slope(ys: number[]): number {
  const n = ys.length;
  if (n < 2) throw new Error("need at least 2 mocks for a slope");
  const meanX = (n - 1) / 2;
  const meanY = ys.reduce((a, b) => a + b, 0) / n;
  let num = 0;
  let den = 0;
  ys.forEach((y, x) => {
    num += (x - meanX) * (y - meanY);
    den += (x - meanX) ** 2;
  });
  return num / den;
}

export interface Row {
  dim: string;
  first: number;
  last: number;
  slope: number;
  recent: number;
}

export function analyse(log: Mock[]): Row[] {
  if (log.length < 2) throw new Error("need at least 2 mocks for a slope");
  return Object.keys(log[0].scores).map((dim) => {
    const ys = log.map((m) => m.scores[dim]);
    const tail = ys.slice(-3);
    return { dim, first: ys[0], last: ys[ys.length - 1], slope: slope(ys), recent: tail.reduce((a, b) => a + b, 0) / tail.length };
  });
}

export function report(log: Mock[]): string {
  const rows = analyse(log);
  const byNaive = [...rows].sort((a, b) => b.last - b.first - (a.last - a.first))[0];
  const bySlope = [...rows].sort((a, b) => b.slope - a.slope)[0];
  const weakest = [...rows].sort((a, b) => a.recent - b.recent)[0];
  const done = new Set(log.map((m) => m.caseName));
  const nextCases = (STRESSES[weakest.dim] ?? []).filter((c) => !done.has(c));
  return [
    `mocks: ${log.length} (${log[0].caseName} ... ${log[log.length - 1].caseName})`,
    `${"dimension".padEnd(14)}first last delta  slope/mock  mean(last 3)`,
    ...rows.map((r) => `${r.dim.padEnd(14)}${String(r.first).padEnd(6)}${String(r.last).padEnd(5)}${(r.last >= r.first ? "+" : "") + (r.last - r.first)}     ${(r.slope >= 0 ? "+" : "") + r.slope.toFixed(2)}       ${r.recent.toFixed(2)}`),
    "",
    `first-vs-last says most improved: ${byNaive.dim} (${byNaive.last - byNaive.first >= 0 ? "+" : ""}${byNaive.last - byNaive.first})`,
    `slope says most improved:         ${bySlope.dim} (+${bySlope.slope.toFixed(2)} per mock)`,
    `weakest now (mean of last 3):     ${weakest.dim} (${weakest.recent.toFixed(2)})`,
    `next cases for ${weakest.dim}: ${nextCases.join(", ") || "none left, pick any"}`,
  ].join("\n");
}

Part 6 — From gaps to next week 🟡 Intermediateالجزء 6 — من الفجوات للأسبوع الجاي

English

⏱ Timed prompt, 5 minutes, after every mock. Tag each finding: silent, no numbers, weak deep dive, assumed, forgot NFRs, no verification, defensive. Then map each tag to one drill and put the drill in your calendar. Stop at 5 minutes.

Model solution. Each finding has a drill: silent means talk-through reps, no numbers means estimation reps, a weak deep dive means going down a level in one case: schema, then index, then failure mode. Three drills a week is the cap, because a longer list gets done by nobody. next-week.ts counts findings across the last three mocks and picks the most frequent. Sorting a handful of tags is trivially cheap, so there's no complexity to discuss; the brute force here is doing "more mocks" with no drill, which repeats the mistake instead of fixing it.

Being nervous is normal. Two practical moves help: warm up on an easy problem right before the real one, and state your plan out loud before you start ("I'll ask questions, say a brute force, then improve it"). The plan gives you something to do with the first minute. This is practice advice, not medical advice.

Finally, the README's eight exit tests map onto lessons in this section. Treat them as the final checklist.

export const DRILLS = {
  silent: { drill: "Talk-through reps: one problem out loud, recorded, no silent gap over 20 s", minutes: 30 },
  "no-numbers": { drill: "Estimation reps: 5 estimates, each ending in a decision", minutes: 25 },
  "weak-deep-dive": { drill: "One case, one level down: schema, index, failure mode", minutes: 45 },
  assumed: { drill: "First-5-minutes reps: 5 prompts, only the questions you would ask", minutes: 25 },
  "forgot-nfr": { drill: "NFR card: for 3 prompts, say all 5 families before drawing", minutes: 15 },
  "no-verification": { drill: "Boundary reps: 3 problems, trace a boundary and an empty input", minutes: 20 },
  defensive: { drill: "Re-listen, repeat each point in your own words, write one change", minutes: 15 },
} as const;

export type Finding = keyof typeof DRILLS;

export function planWeek(findings: Finding[][], maxDrills = 3): { finding: Finding; seen: number; drill: string; minutes: number }[] {
  const counts = new Map<Finding, number>();
  for (const mock of findings) {
    for (const f of new Set(mock)) {
      if (!(f in DRILLS)) throw new Error(`unknown finding: ${f}`);
      counts.set(f, (counts.get(f) ?? 0) + 1);
    }
  }
  return [...counts.entries()]
    .sort((a, b) => b[1] - a[1])
    .slice(0, maxDrills)
    .map(([finding, seen]) => ({ finding, seen, ...DRILLS[finding] }));
}

2. Talk ratio 🟡 medium Add talkRatio(segs): the candidate's share of total speaking time. Compare transcripts A and B. A candidate who talks 95% of the time is often not listening, so the number needs reading, not maximising.
ضيف talkRatio(segs): نسبة كلام الـ candidate من إجمالي وقت الكلام. قارن A و B. الـ candidate اللي بيتكلم 95% من الوقت غالبًا مش بيسمع، فالرقم محتاج قراية مش maximize.
Solution · الحل 
// حل التمرين: نسبة كلام الـ candidate من إجمالي وقت الكلام
import type { Segment } from "./review.ts";

export function talkRatio(segs: Segment[]): number {
  const spoke = (who: "C" | "I") => segs.filter((s) => s.speaker === who).reduce((a, s) => a + (s.end - s.start), 0);
  const total = spoke("C") + spoke("I");
  if (total === 0) return 0;
  return spoke("C") / total;
}

✔ edge: an empty transcript is 0, not NaN (0.2376ms)
✔ real files: the strong transcript talks more of the time (0.7821ms)

Cheat sheet · الخلاصة

  • Sources: a senior colleague (best, scarce), peers (cheap, repeatable), interviewing.io, Pramp now on Aced Practice, Exponent now Aced. Prices change, check them yourself.
  • Always ask before recording. If they decline, record only your own voice.
  • 45 + 15 minutes. Read the prompt once, no help early, ask "why that?", keep the clock aloud, write minutes.
  • A seeded card makes the mock reproducible, and a friend who isn't a Senior can run it.
  • Review with three hand-written lines: where I went silent, where I assumed, what NFR I forgot.
  • Silence is end to next start. Tools point at moments; they don't grade you.
  • Feedback has a score, a minute and a next action, or it isn't feedback.
  • 10 recorded design mocks, scored the same way, and read by slope plus the last three.
  • After each mock: 5 minutes, at most three drills, in the calendar.
  • Nervous: warm up on an easy one, say your plan out loud.
