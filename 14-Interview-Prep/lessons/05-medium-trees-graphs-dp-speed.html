Why this matters · ليه ده مهم

English

The README sets two clocks. Twenty-five minutes for a Medium while talking is the pass mark. Fifteen to twenty minutes with clean code the first time is what leaves room for the follow-up, and the follow-up is where a Senior gets separated from a Mid. This lesson drills the categories lesson 04 left out: linked lists, trees, tries, heaps, backtracking, graphs and DP. It also gives you a log that shows where your minutes really go, because "I need to get faster" is not something you can practise.

None of this is only for interviews. Cycle checks guard migration runners, tree walks run over category tables, and top-K runs over sales streams.

Part 1 — Where the minutes go 🟡 Intermediateالجزء 1 — الدقايق بتروح فين

⏱ Timed prompt · 12 minutes You keep a CSV of practice attempts: id,understood,planned,coded,tested,rewrites, where the four timestamps are mm:ss since you started the timer. Write pace.ts: print the median minutes per phase beside its budget (understand 3, plan 5, code 12, test 5), and name the phase that leaks the most. A malformed row must fail with its line number.
عندك CSV بمحاولات التمرين: id,understood,planned,coded,tested,rewrites، والأربع timestamps بصيغة mm:ss من لحظة ما شغّلت التايمر. اكتب pace.ts: اطبع الـ median بالدقايق لكل phase جنب الميزانية بتاعتها (understand ‏3، plan ‏5، code ‏12، test ‏5)، وقول أنهي phase بتسرّب وقت أكتر. وأي سطر بايظ لازم يقع برقم السطر بتاعه.
English

Brute force first. Log only the total minutes per attempt. It is one number and it says "too slow" without saying where. So log four timestamps instead, and report a per-phase median. Complexity before running it: with a attempts and 4 phases, each median sorts a values, so O(a log a) per phase. Nothing here needs optimizing.

Why the median. One disaster attempt moves an average and leaves a median alone. You want the typical attempt.

The budget. 25 minutes split as understand 3, plan 5, code 12, test 5. Going from 25 to 15–20 comes from templates in your hands and fewer rewrites, not from thinking less: understanding stays at 3 minutes, because cutting it is exactly what causes rewrites. The 15-minute split in the diagram is a target I am proposing for you to test against your own log, not a published standard.

Keep talking. A silent fast solve still scores badly, because the interviewer can only score what they can see. The clock is there to protect the conversation, not to replace it.

import { readFileSync } from "node:fs";

// الميزانية بالدقايق لكل phase، ومجموعها 25
export const BUDGET = { understand: 3, plan: 5, code: 12, test: 5 } as const;
export type Phase = keyof typeof BUDGET;
const PHASES = Object.keys(BUDGET) as Phase[];

export interface Attempt {
  id: string;
  minutes: Record<Phase, number>;
  rewrites: number;
}

// بيحوّل mm:ss لدقايق، وأي صيغة غلط بترمي error بدل NaN ساكت
function clock(text: string | undefined, line: number): number {
  const match = /^(\d+):([0-5]\d)$/.exec(text ?? "");
  if (!match) throw new Error(`line ${line}: bad timestamp "${text}"`);
  return Number(match[1]) + Number(match[2]) / 60;
}

export function parseAttempts(csv: string): Attempt[] {
  const rows = csv.trim().split(/\r?\n/).slice(1);
  return rows.map((row, index) => {
    const line = index + 2;
    const [id, understood, planned, coded, tested, rewrites] = row.split(",");
    const marks = [understood, planned, coded, tested].map((t) => clock(t, line));
    // لازم الوقت يزيد من phase للي بعدها، وإلا السطر متسجّل غلط
    marks.forEach((mark, i) => {
      if (i > 0 && mark < marks[i - 1]) throw new Error(`line ${line}: time goes backwards`);
    });
    return {
      id: id ?? "?",
      rewrites: Number(rewrites ?? 0),
      minutes: {
        understand: marks[0],
        plan: marks[1] - marks[0],
        code: marks[2] - marks[1],
        test: marks[3] - marks[2],
      },
    };
  });
}

// الـ median مش الـ average: محاولة كارثية واحدة متبوّظش الرقم
export function median(values: readonly number[]): number {
  if (values.length === 0) throw new RangeError("median of an empty list");
  const sorted = values.toSorted((a, b) => a - b);
  const mid = sorted.length >> 1;
  return sorted.length % 2 === 1 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
}

export function paceReport(attempts: readonly Attempt[]) {
  const rows = PHASES.map((phase) => {
    const value = median(attempts.map((a) => a.minutes[phase]));
    return { phase, median: value, budget: BUDGET[phase], over: value - BUDGET[phase] };
  });
  const worst = rows.reduce((a, b) => (b.over > a.over ? b : a));
  return { rows, leak: worst.over > 0 ? worst.phase : null };
}

const total = (a: Attempt) => PHASES.reduce((sum, p) => sum + a.minutes[p], 0);

  console.log("phase       median  budget  over");
  for (const r of rows) {

Part 2 — Linked lists 🟡 Intermediateالجزء 2 — الـ linked lists

⏱ Timed prompt · 20 minutes for both
  1. A retry queue is a singly linked chain of jobs. Remove the job that is n places from the end and return the new head. Ask what happens when n is out of range.
  2. A chain of URL redirects is stored as linked records. Decide whether following it ever comes back on itself. Use constant extra memory.
  1. عندك retry queue على شكل chain من الـ jobs (singly linked). امسح الـ job اللي مكانها n من الآخر ورجّع الـ head الجديد. واسأل: لو n برة النطاق يحصل إيه؟
  2. عندك سلسلة URL redirects متخزنة كـ records مربوطة ببعض. قرر: هل لو مشيت وراها هترجع لنفس المكان؟ والـ memory الزيادة لازم تبقى ثابتة.
English

Every measurement in this lesson uses the small doubling.ts harness below: call tick() once per unit of work. x2.00 per doubling means linear and x4.00 means quadratic. Wall times are marked ≈ and are secondary, because this is a loaded Windows machine.

Section 01 teaches the structure; this is the drill. Removal. Brute force: copy the nodes into an array, O(L) time and O(L) memory. Next idea: count the length in one pass, walk to the spot in a second. The two-pointer version keeps a gap of n between lead and trail. All three are O(L). Expect the gap version to do no fewer pointer moves than the two-pass one (both are 2L − n); its only advantage is that it reads the chain once, which matters when you can't re-read it.

The dummy head. A fake node before the head turns "remove the head" into the ordinary case. Without it you need a special branch, and that branch is where the bug lives.

The loop. Brute force: remember every node in a Set, O(L) time and O(L) memory. Floyd's slow and fast pointers: O(L) time and O(1) memory, because if there is a cycle the fast pointer enters it and closes the gap by one step per iteration. Expect it to do more hops than the Set, not fewer. You pay hops to save memory.

الـ dummy قبل الـ head. الخطوة الأولى: lead بيسبق بـ n خطوات. التانية: الاتنين يمشوا مع بعض لحد ما lead يوصل لآخر node، فبيقف trail قبل المطلوب مسحها بالظبط. التالتة: trail.next = trail.next.next والـ d اتشالت. ولو كانت المطلوبة هي الـ head، trail هيفضل عند الـ dummy والكود نفسه يشتغل من غير أي حالة خاصة.
// بيشغّل run على أحجام متزايدة ويطبع عدد الـ ops ونسبة الزيادة
// الـ ops هي الدليل، والـ ms رقم ثانوي على جهاز عليه ضغط
export type Tick = () => void;
export const noop: Tick = () => {};

export function doubling(name: string, run: (n: number, tick: Tick) => void, sizes: number[]): void {
  let previous = 0;
  for (const n of sizes) {
    let ops = 0;
    const started = performance.now();
    run(n, () => { ops++; });
    const ms = performance.now() - started;
    const ratio = previous ? `x${(ops / previous).toFixed(2)}` : "";
    console.log(`${name.padEnd(14)} n=${String(n).padStart(7)} ops=${String(ops).padStart(11)} ${ratio.padEnd(7)} ms≈${ms.toFixed(1)}`);
    previous = ops;
  }
}

import { noop, type Tick } from "./doubling.ts";

export interface Job {
  id: string;
  next: Job | null;
}

export function chainOf(ids: readonly string[]): Job | null {
  const dummy: Job = { id: "dummy", next: null };
  let tail = dummy;
  for (const id of ids) {
    tail.next = { id, next: null };
    tail = tail.next;
  }
  return dummy.next;
}

export function idsOf(head: Job | null): string[] {
  const ids: string[] = [];
  for (let cur = head; cur !== null; cur = cur.next) ids.push(cur.id);
  return ids;
}

// الـ brute: انسخ الـ nodes في array، وتمن ده O(L) memory
export function removeByArray(head: Job | null, n: number, tick: Tick = noop): Job | null {
  const nodes: Job[] = [];
  for (let cur = head; cur !== null; cur = cur.next) {
    tick();
    nodes.push(cur);
  }
  const target = nodes.length - n;
  if (n < 1 || target < 0) throw new RangeError(`no job ${n} from the end`);
  if (target === 0) return nodes[1] ?? null;
  nodes[target - 1].next = nodes[target].next;
  return head;
}

// الـ brute التاني: عدّ الطول في لفة، وامشي للمكان في لفة تانية
export function removeTwoPass(head: Job | null, n: number, tick: Tick = noop): Job | null {
  let length = 0;
  for (let cur = head; cur !== null; cur = cur.next) {
    tick();
    length++;
  }
  if (n < 1 || n > length) throw new RangeError(`no job ${n} from the end`);
  const dummy: Job = { id: "dummy", next: head };
  let before = dummy;
  for (let i = 0; i < length - n; i++) {
    tick();
    before = before.next!;
  }
  before.next = before.next!.next;
  return dummy.next;
}

// الحل: مؤشرين بينهم مسافة n، والـ dummy بيخلّي حذف الـ head حالة عادية
export function removeNthFromEnd(head: Job | null, n: number, tick: Tick = noop): Job | null {
  if (n < 1) throw new RangeError(`no job ${n} from the end`);
  const dummy: Job = { id: "dummy", next: head };
  let lead: Job = dummy;
  for (let i = 0; i < n; i++) {
    tick();
    if (lead.next === null) throw new RangeError(`no job ${n} from the end`);
    lead = lead.next;
  }
  let trail: Job = dummy;
  while (lead.next !== null) {
    tick();
    tick();
    lead = lead.next;
    trail = trail.next!;
  }
  trail.next = trail.next!.next;
  return dummy.next;
}

// الـ brute: افتكر كل path شفته، O(L) time و O(L) memory
export function hasLoopWithSet(head: Redirect | null, tick: Tick = noop): { loop: boolean; remembered: number } {
  const seen = new Set<Redirect>();
  for (let cur = head; cur !== null; cur = cur.next) {
    tick();
    if (seen.has(cur)) return { loop: true, remembered: seen.size };
    seen.add(cur);
  }
  return { loop: false, remembered: seen.size };
}

// الحل: slow خطوة و fast خطوتين، O(L) time و O(1) memory
export function hasLoop(head: Redirect | null, tick: Tick = noop): boolean {
  let slow = head;
  let fast = head;
  while (fast !== null && fast.next !== null) {
    tick();
    tick();
    tick();
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) return true;
  }
  return false;
}

English

Section 01 covers tree basics. Lowest common category. Brute force: walk down from the root and, at every level, ask each child "do you contain both?" with a fresh DFS. That is O(n·h), so O(n²) when the tree is a chain. Model: one post-order DFS that returns how many targets are in each subtree; the first node to reach both is the answer. O(n) time, O(h) stack.

Emails by level. Brute force: one DFS per depth, O(n·h). Model: a frontier list per level, O(n), with no shift() and no recursion.

Valid index. The classic bug is comparing a node only with its parent. A key can satisfy its parent and still violate a grandparent, so each node has to inherit a (low, high) range from all of its ancestors. O(n) time. Brute force that is still correct: in-order to an array and check it is strictly increasing, O(n) memory.

Say the recursion limit out loud. A linked-shaped tree makes recursion depth equal n, and Node's stack runs out at roughly 9,500 simple frames here (it depends on frame size). So after writing the recursive version, tell the interviewer the depth limit, and offer the iterative one: an explicit stack in a heap-allocated array has no such limit. Don't suggest raising --stack-size: it can crash the process instead of throwing.

export interface Category {
  id: string;
  children: Category[];
}

function contains(node: Category, id: string, tick: Tick): boolean {
  tick();
  return node.id === id || node.children.some((child) => contains(child, id, tick));
}

// الـ brute: انزل مستوى مستوى، وكل مستوى بيعيد الـ DFS، يعني ⁦O(n·h)⁩
export function lowestCommonBrute(root: Category, a: string, b: string, tick: Tick = noop): Category | null {
  if (!contains(root, a, tick) || !contains(root, b, tick)) return null;
  let current = root;
  for (;;) {
    const deeper = current.children.find((c) => contains(c, a, tick) && contains(c, b, tick));
    if (!deeper) return current;
    current = deeper;
  }
}

// الحل: DFS واحد post-order، وأول node تجمّع الاتنين هي الأعمق
export function lowestCommon(root: Category, a: string, b: string, tick: Tick = noop): Category | null {
  const need = a === b ? 1 : 2;
  let answer: Category | null = null;
  const visit = (node: Category): number => {
    tick();
    let found = node.id === a || node.id === b ? 1 : 0;
    for (const child of node.children) {
      found += visit(child);
      if (answer !== null) return found;
    }
    if (found === need) answer = node;
    return found;
  };
  visit(root);
  return answer;
}

// نفس الإجابة من غير recursion: parent map ومؤشر طالع لفوق
export function lowestCommonIterative(root: Category, a: string, b: string, tick: Tick = noop): Category | null {
  const parent = new Map<string, Category | null>([[root.id, null]]);
  const nodes = new Map<string, Category>([[root.id, root]]);
  const stack = [root];
  while (stack.length > 0) {
    const node = stack.pop()!;
    tick();
    for (const child of node.children) {
      parent.set(child.id, node);
      nodes.set(child.id, child);
      stack.push(child);
    }
  }
  if (!nodes.has(a) || !nodes.has(b)) return null;
  const ancestors = new Set<string>();
  for (let cur: Category | null = nodes.get(a)!; cur; cur = parent.get(cur.id) ?? null) ancestors.add(cur.id);
  for (let cur: Category | null = nodes.get(b)!; cur; cur = parent.get(cur.id) ?? null) {
    if (ancestors.has(cur.id)) return cur;
  }
  return null;
}

export interface Employee {
  email: string;
  reports: Employee[];
}

// الـ brute: DFS كامل لكل depth، يعني ⁦O(n·h)⁩
export function emailsByLevelBrute(ceo: Employee | null, tick: Tick = noop): string[][] {
  const levels: string[][] = [];
  const collect = (e: Employee, depth: number, target: number, into: string[]): void => {
    tick();
    if (depth === target) { into.push(e.email); return; }
    for (const report of e.reports) collect(report, depth + 1, target, into);
  };
  if (ceo === null) return levels;
  for (let target = 0; ; target++) {
    const level: string[] = [];
    collect(ceo, 0, target, level);
    if (level.length === 0) return levels;
    levels.push(level);
  }
}

// الحل: frontier لكل مستوى، من غير shift ومن غير recursion
export function emailsByLevel(ceo: Employee | null, tick: Tick = noop): string[][] {
  const levels: string[][] = [];
  let frontier = ceo === null ? [] : [ceo];
  while (frontier.length > 0) {
    levels.push(frontier.map((e) => e.email));
    const next: Employee[] = [];
    for (const employee of frontier) {
      tick();
      for (const report of employee.reports) next.push(report);
    }
    frontier = next;
  }
  return levels;
}

export interface IndexNode {
  key: number;
  left: IndexNode | null;
  right: IndexNode | null;
}

// الغلط الكلاسيكي: بيقارن بالأب بس، وبيعدّي شجرة باظت
export function isValidParentOnly(node: IndexNode | null): boolean {
  if (node === null) return true;
  if (node.left !== null && node.left.key >= node.key) return false;
  if (node.right !== null && node.right.key <= node.key) return false;
  return isValidParentOnly(node.left) && isValidParentOnly(node.right);
}

// الـ brute الصحيح: in-order في array وشوف هو متزايد ولا لأ، O(n) memory
export function isValidByInorder(root: IndexNode | null, tick: Tick = noop): boolean {
  const keys: number[] = [];
  const stack: IndexNode[] = [];
  let cur = root;
  while (cur !== null || stack.length > 0) {
    while (cur !== null) { stack.push(cur); cur = cur.left; }
    const node = stack.pop()!;
    tick();
    keys.push(node.key);
    cur = node.right;
  }
  return keys.every((key, i) => i === 0 || keys[i - 1] < key);
}

// الحل: كل node ليها نطاق (low, high) موروث من كل أجدادها
export function isValidIndex(root: IndexNode | null, tick: Tick = noop): boolean {
  if (root === null) return true;
  const stack = [{ node: root, low: -Infinity, high: Infinity }];
  while (stack.length > 0) {
    const { node, low, high } = stack.pop()!;
    tick();
    if (node.key <= low || node.key >= high) return false;
    if (node.left) stack.push({ node: node.left, low, high: node.key });
    if (node.right) stack.push({ node: node.right, low: node.key, high });
  }
  return true;
}

English

Prefix search. Brute force: compare the prefix with every SKU, O(n·p) per query. A trie walks the prefix once, then visits only matches, so the query cost doesn't depend on n. The honest competitor is a sorted array with binary search: O(p log n) per query, no extra nodes, and a few lines of code. Section 01 builds both structures. Pick the trie when you need per-node data or many updates; say the alternative out loud either way.

Top K. Brute force: sort everything, O(n log n). A min-heap of size k keeps the weakest of the current best at the root, so a new row either loses one comparison and is dropped, or replaces the root: O(n log k), and O(k) memory.

The heap in JavaScript. JavaScript has no built-in heap, so the roughly 30-line MinHeap is a drill to do in 7 minutes. On LeetCode you may not need it: its support article (seen through a search index on 2026-11-09; a direct fetch was refused) lists @datastructures-js/priority-queue 6.3.5 alongside Node 22.14 and TypeScript 5.7. CoderPad's TypeScript page says it runs TypeScript 4 on Node 16 and packages must be require()d, so platforms differ. // الدريل: اكتب الملف ده من الذاكرة في 7 دقايق
export type Compare<T> = (a: T, b: T) => number;

export class MinHeap<T> {
  #items: T[] = [];
  #compare: Compare<T>;
  constructor(compare: Compare<T>) { this.#compare = compare; }
  get size(): number { return this.#items.length; }
  peek(): T | undefined { return this.#items[0]; }
  push(item: T): void {
    const a = this.#items;
    a.push(item);
    for (let i = a.length - 1; i > 0; ) {
      const parent = (i - 1) >> 1;
      if (this.#compare(a[i], a[parent]) >= 0) break;
      [a[i], a[parent]] = [a[parent], a[i]];
      i = parent;
    }
  }
  pop(): T | undefined {
    const a = this.#items;
    if (a.length <= 1) return a.pop();
    const top = a[0];
    a[0] = a.pop()!;
    for (let i = 0; ; ) {
      let best = i;
      for (const child of [2 * i + 1, 2 * i + 2]) {
        if (child < a.length && this.#compare(a[child], a[best]) < 0) best = child;
      }
      if (best === i) return top;
      [a[i], a[best]] = [a[best], a[i]];
      i = best;
    }
  }
}

import { MinHeap } from "./min-heap.ts";

// الـ brute: قارن الـ prefix بكل SKU حرف حرف، ⁦O(n·p)⁩ لكل query
export function searchByScan(skus: readonly string[], prefix: string, limit: number, tick: Tick = noop): string[] {
  const out: string[] = [];
  for (const sku of skus) {
    let matched = sku.length >= prefix.length;
    for (let i = 0; matched && i < prefix.length; i++) {
      tick();
      matched = sku[i] === prefix[i];
    }
    if (matched) out.push(sku);
    if (out.length === limit) break;
  }
  return out;
}

class TrieNode {
  children = new Map<string, TrieNode>();
  isSku = false;
}

export class SkuTrie {
  #root = new TrieNode();
  nodes = 1;

  insert(sku: string): void {
    let node = this.#root;
    for (const ch of sku) {
      let next = node.children.get(ch);
      if (next === undefined) {
        next = new TrieNode();
        node.children.set(ch, next);
        this.nodes++;
      }
      node = next;
    }
    node.isSku = true;
  }

  // التكلفة: طول الـ ⁦prefix +⁩ الـ nodes اللي بنلفها للنتايج، ومش معتمدة على n
  search(prefix: string, limit: number, tick: Tick = noop): string[] {
    let node = this.#root;
    for (const ch of prefix) {
      tick();
      const next = node.children.get(ch);
      if (next === undefined) return [];
      node = next;
    }
    const out: string[] = [];
    const stack: Array<[TrieNode, string]> = [[node, prefix]];
    while (stack.length > 0 && out.length < limit) {
      const [current, text] = stack.pop()!;
      tick();
      if (current.isSku) out.push(text);
      for (const [ch, child] of current.children) stack.push([child, text + ch]);
    }
    return out;
  }
}

// البديل الأبسط: array مترتبة و binary search على أول ⁦SKU >=⁩ الـ prefix
export function searchSorted(sorted: readonly string[], prefix: string, limit: number, tick: Tick = noop): string[] {
  let low = 0;
  let high = sorted.length;
  while (low < high) {
    tick();
    const mid = (low + high) >> 1;
    if (sorted[mid] < prefix) low = mid + 1;
    else high = mid;
  }
  const out: string[] = [];
  for (let i = low; i < sorted.length && out.length < limit && sorted[i].startsWith(prefix); i++) {
    tick();
    out.push(sorted[i]);
  }
  return out;
}

export interface Sale {
  sku: string;
  units: number;
}

// كسر التعادل بالـ sku عشان الناتج يبقى deterministic
const betterFirst = (a: Sale, b: Sale): number => b.units - a.units || (a.sku < b.sku ? -1 : 1);

// الـ brute: رتب الكل، ⁦O(n log n)⁩
export function topKBySort(sales: readonly Sale[], k: number, tick: Tick = noop): Sale[] {
  return sales.toSorted((a, b) => { tick(); return betterFirst(a, b); }).slice(0, k);
}

// الحل: min-heap حجمه k، والـ root هو أضعف واحد لسه جوه، ⁦O(n log k)⁩
export function topK(sales: readonly Sale[], k: number, tick: Tick = noop): Sale[] {
  if (k <= 0) return [];
  const heap = new MinHeap<Sale>((a, b) => { tick(); return betterFirst(b, a); });
  for (const sale of sales) {
    if (heap.size < k) {
      heap.push(sale);
    } else {
      tick();
      if (betterFirst(sale, heap.peek()!) < 0) {
        heap.pop();
        heap.push(sale);
      }
    }
  }
  const out: Sale[] = [];
  while (heap.size > 0) out.push(heap.pop()!);
  return out.reverse();
}

⏱ Timed prompt · 20 minutes A checkout offers add-ons, each with an id and a price in integer cents. List every non-empty combination of add-ons whose total is within a budget. Each add-on is used at most once, and two add-ons at the same price are different choices. Ask whether a price can be zero or negative.
الـ checkout فيه add-ons، كل واحدة ليها id وسعر بالقروش (integer). اطلع كل combination مش فاضية مجموعها جوه الميزانية. كل add-on تتاخد مرة واحدة بالكتير، واتنين بنفس السعر يعتبروا اختيارين مختلفين. واسأل: ينفع سعر يبقى صفر أو سالب؟
English

Brute force. Generate all 2n subsets with a bitmask and filter: O(n·2n). Model. Backtracking with the choose, explore, unchoose template, over add-ons sorted by price. Because the array is sorted, the moment one add-on is too expensive, every later one is too, so you break. Pruning needs prices to be non-negative, so that question matters.

Worst-case complexity stays O(n·2n), because when the budget is loose every subset is a valid answer and you have to output all of them. Backtracking saves work only on the parts of the tree you can rule out. Say that, so nobody thinks pruning changed the worst case.

Recursion depth is at most n, which is small here, so recursion is fine for this one. A real checkout should also cap n, since 2n results is itself a denial of service.

import { noop, type Tick } from "./doubling.ts";

export interface AddOn {
  id: string;
  cents: number;
}

// الـ brute: كل الـ subsets بـ bitmask، وبعدين فلتر، ⁦O(n·2^n)⁩
export function combosByMask(addOns: readonly AddOn[], budget: number, tick: Tick = noop): AddOn[][] {
  const out: AddOn[][] = [];
  for (let mask = 1; mask < 1 << addOns.length; mask++) {
    const pick: AddOn[] = [];
    let total = 0;
    for (let i = 0; i < addOns.length; i++) {
      tick();
      if (mask & (1 << i)) {
        pick.push(addOns[i]);
        total += addOns[i].cents;
      }
    }
    if (total <= budget) out.push(pick);
  }
  return out;
}

// الـ backtracking: choose ثم explore ثم unchoose
export function combosWithin(addOns: readonly AddOn[], budget: number, prune = true, tick: Tick = noop): AddOn[][] {
  const sorted = addOns.toSorted((a, b) => a.cents - b.cents);
  const out: AddOn[][] = [];
  const chosen: AddOn[] = [];
  const explore = (start: number, remaining: number): void => {
    tick();
    if (chosen.length > 0 && remaining >= 0) out.push([...chosen]);
    for (let i = start; i < sorted.length; i++) {
      const addOn = sorted[i];
      // لأن الـ array مترتبة: لو ده غالي، كل اللي بعده أغلى
      if (prune && addOn.cents > remaining) break;
      chosen.push(addOn);
      explore(i + 1, remaining - addOn.cents);
      chosen.pop();
    }
  };
  explore(0, budget);
  return out;
}

Part 6 — Graphs 🟡 Intermediateالجزء 6 — الـ graphs

⏱ Timed prompt · 45 minutes for all three (15 each)
  1. Sellers are linked when they share a payout account. Group the sellers into connected networks.
  2. Services depend on services, and the graph can have cycles. Deep-copy it, so that a shared dependency stays one object in the copy.
  3. Migrations depend on migrations. Say whether all of them can run.
  1. البايعين مرتبطين لما يشتركوا في حساب تحويل. قسّمهم لشبكات متصلة.
  2. الـ services بتعتمد على services، والـ graph ممكن يبقى فيه cycles. اعمل deep copy بحيث الـ dependency المشتركة تفضل object واحد في النسخة.
  3. الـ migrations بتعتمد على migrations. قول هل ينفع تشغيلهم كلهم.
English

Section 01 teaches BFS and DFS; here the point is reflexes. Networks. Brute force: give every seller a label and re-scan all links until nothing changes, O(V·E). Model: adjacency list and BFS, O(V+E), using the head-index queue. The queue array doubles as the component.

Clone. Brute force: recursive copy with no memory, which overflows on a cycle and duplicates shared nodes, exponential on stacked diamonds. Model: a Map from original to copy that also serves as the visited set, O(V+E). In real code, structuredClone handles cycles; mention it, then implement what they asked.

Can all migrations run. Brute force: scan for any migration whose prerequisites are done, repeat, O(V²·E) as written. Model: Kahn's algorithm, O(V+E): keep a count of unfinished prerequisites and release a migration when its count hits zero. If fewer than V get released, a cycle exists.

Mark visited when you enqueue, not when you dequeue. Marking on dequeue lets the same node enter the queue once per incoming edge, so the queue grows to about E entries instead of V. On a dense graph that is the difference between a thousand and half a million.

import { noop, type Tick } from "./doubling.ts";

export type Link = readonly [string, string];

// الـ brute: كرّر لفة على كل الـ links لحد ما الـ labels تثبت، ⁦O(V·E)⁩
export function networksByRelabel(sellers: readonly string[], links: readonly Link[], tick: Tick = noop): string[][] {
  const label = new Map(sellers.map((seller, i) => [seller, i]));
  let changed = true;
  while (changed) {
    changed = false;
    for (const [a, b] of links) {
      tick();
      const low = Math.min(label.get(a)!, label.get(b)!);
      if (label.get(a) !== low || label.get(b) !== low) {
        label.set(a, low);
        label.set(b, low);
        changed = true;
      }
    }
  }
  return [...Map.groupBy(sellers, (s) => label.get(s)!).values()];
}

// الحل: adjacency list و BFS، والـ queue نفسها هي الـ component
export function sellerNetworks(sellers: readonly string[], links: readonly Link[], tick: Tick = noop): string[][] {
  const neighbours = new Map<string, string[]>(sellers.map((s) => [s, []]));
  for (const [a, b] of links) {
    neighbours.get(a)!.push(b);
    neighbours.get(b)!.push(a);
  }
  const seen = new Set<string>();
  const networks: string[][] = [];
  for (const start of sellers) {
    if (seen.has(start)) continue;
    seen.add(start);
    const queue = [start];
    // مؤشر head بدل shift، عشان shift بتحرك كل العناصر كل مرة
    for (let head = 0; head < queue.length; head++) {
      tick();
      for (const next of neighbours.get(queue[head])!) {
        tick();
        if (seen.has(next)) continue;
        // علّم وقت الإضافة للـ queue، مش وقت الخروج منها
        seen.add(next);
        queue.push(next);
      }
    }
    networks.push(queue);
  }
  return networks;
}

// تجربة: بنعدّ كام مرة دخل عنصر الـ queue في الطريقتين
export function countEnqueues(neighbours: readonly number[][], when: "enqueue" | "dequeue"): number {
  const seen = new Uint8Array(neighbours.length);
  const queue = [0];
  if (when === "enqueue") seen[0] = 1;
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    if (when === "dequeue") {
      if (seen[node]) continue;
      seen[node] = 1;
    }
    for (const next of neighbours[node]) {
      if (seen[next]) continue;
      if (when === "enqueue") seen[next] = 1;
      queue.push(next);
    }
  }
  return queue.length;
}

export interface Service {
  name: string;
  deps: Service[];
}

// الـ brute: نسخ عمياني، بيقع على cycle وبينفجر على الـ diamonds
export function cloneNaive(service: Service, tick: Tick = noop): Service {
  tick();
  return { name: service.name, deps: service.deps.map((dep) => cloneNaive(dep, tick)) };
}

// الحل: Map من الأصل للنسخة، وهي كمان الـ visited
export function cloneGraph(root: Service, tick: Tick = noop): Service {
  const copies = new Map<Service, Service>([[root, { name: root.name, deps: [] }]]);
  const queue = [root];
  for (let head = 0; head < queue.length; head++) {
    const original = queue[head];
    const copy = copies.get(original)!;
    for (const dep of original.deps) {
      tick();
      let depCopy = copies.get(dep);
      if (depCopy === undefined) {
        depCopy = { name: dep.name, deps: [] };
        copies.set(dep, depCopy);
        queue.push(dep);
      }
      copy.deps.push(depCopy);
    }
  }
  return copies.get(root)!;
}

export type Dep = readonly [before: string, after: string];

// الـ brute: لفّ على الكل وشغّل أي migration جاهزة، ⁦O(V·E)⁩
export function canRunAllByScan(migrations: readonly string[], deps: readonly Dep[], tick: Tick = noop): boolean {
  const done = new Set<string>();
  let progress = true;
  while (progress) {
    progress = false;
    for (const migration of migrations) {
      if (done.has(migration)) continue;
      let ready = true;
      for (const [before, after] of deps) {
        tick();
        if (after === migration && !done.has(before)) { ready = false; break; }
      }
      if (ready) { done.add(migration); progress = true; }
    }
  }
  return done.size === migrations.length;
}

// الحل: Kahn، لو فيه cycle فيه migrations عمر الـ indegree بتاعها ما هيوصل صفر
export function canRunAll(migrations: readonly string[], deps: readonly Dep[], tick: Tick = noop): boolean {
  const waitingOn = new Map<string, number>(migrations.map((m) => [m, 0]));
  const unlocks = new Map<string, string[]>(migrations.map((m) => [m, []]));
  for (const [before, after] of deps) {
    if (!unlocks.has(before) || !waitingOn.has(after)) throw new Error(`unknown migration in ${before} -> ${after}`);
    unlocks.get(before)!.push(after);
    waitingOn.set(after, waitingOn.get(after)! + 1);
  }
  const ready = migrations.filter((m) => waitingOn.get(m) === 0);
  for (let head = 0; head < ready.length; head++) {
    tick();
    for (const after of unlocks.get(ready[head])!) {
      tick();
      const left = waitingOn.get(after)! - 1;
      waitingOn.set(after, left);
      if (left === 0) ready.push(after);
    }
  }
  return ready.length === migrations.length;
}

⏱ Timed prompt · 40 minutes for both (20 + 20)
  1. Box types each hold units and cost cents, with unlimited stock. Return the minimum cost to pack at least quantity units. Ask: exact or at least? Is a zero-unit box possible?
  2. Given two customers' purchase histories as ordered lists of SKUs, return the length of the longest sequence of purchases they share in the same order, not necessarily adjacent. Then return the sequence itself.
  1. عندك أنواع صناديق، كل نوع بيشيل units وبسعر cents، والمخزون مفتوح. رجّع أقل تكلفة تعبّي بيها quantity وحدة على الأقل. واسأل: بالظبط ولا على الأقل؟ وينفع صندوق بصفر وحدة؟
  2. عندك تاريخ شراء عميلين كـ lists مترتبة من الـ SKUs. رجّع طول أطول sequence مشتركة بنفس الترتيب ومش لازم تبقى متجاورة. وبعدها رجّع الـ sequence نفسها.
English

Section 01 teaches DP from scratch. Under a clock you walk the ladder in this order, because each rung gives you a working program to fall back on:

  1. Recursion: state the recurrence out loud. Exponential: O(bQ) for b box types, O(2m+n) for the histories.
  2. Memo: the same code, plus a cache keyed by the state. Now O(states × choices): O(Q·b) and O(m·n).
  3. Table: fill the same states bottom-up. Same complexity, no recursion and no stack risk.
  4. Space-optimized: keep only what the recurrence reads. Packaging keeps the last maxUnits values in a ring. The histories keep two rows, O(min(m, n)) memory, but two rows can no longer reconstruct the sequence, so the follow-up "return the sequence" needs the full table.

In an interview the table is usually where you stop. Name the space optimization and code it only if asked.

"At least" changes the recurrence. Going negative clamps to zero: best[max(0, need - units)]. A bigger box can be cheaper than an exact fit, and the test below pins that.

                 time          memory        can return the sequence?
recursion        O(2^(m+n))    O(m+n) stack  yes, by carrying it
memo             O(m*n)        O(m*n)        yes
table            O(m*n)        O(m*n)        yes
two rows         O(m*n)        O(min(m,n))   no
السلم من فوق لتحت: الـ recursion وقتها O(2^(m+n)) و memory قد العمق وبترجّع الـ sequence لو شيلتها معاك. الـ memo والـ table الاتنين O(m*n) وقت و O(m*n) memory وبيرجّعوا الـ sequence. الـ two rows نفس الوقت و O(min(m,n)) memory بس مبقتش تقدر ترجّع الـ sequence.
import { noop, type Tick } from "./doubling.ts";

export interface BoxType {
  units: number;
  cents: number;
}

function validate(boxes: readonly BoxType[]): void {
  // صندوق بـ 0 وحدة يخلّي الـ recursion متخلصش أبدًا
  if (boxes.some((b) => b.units < 1)) throw new RangeError("a box must hold at least one unit");
}

// الخطوة 1: recursion صريحة، exponential في الـ quantity
export function cheapestRecursive(quantity: number, boxes: readonly BoxType[], tick: Tick = noop): number {
  validate(boxes);
  const solve = (need: number): number => {
    tick();
    if (need <= 0) return 0;
    let best = Infinity;
    for (const box of boxes) best = Math.min(best, box.cents + solve(need - box.units));
    return best;
  };
  return solve(quantity);
}

// الخطوة 2: نفس الـ recursion بـ memo، كل need بتتحسب مرة
export function cheapestMemo(quantity: number, boxes: readonly BoxType[], tick: Tick = noop): number {
  validate(boxes);
  const memo = new Map<number, number>();
  const solve = (need: number): number => {
    tick();
    if (need <= 0) return 0;
    const known = memo.get(need);
    if (known !== undefined) return known;
    let best = Infinity;
    for (const box of boxes) best = Math.min(best, box.cents + solve(need - box.units));
    memo.set(need, best);
    return best;
  };
  return solve(quantity);
}

// الخطوة 3: جدول من تحت لفوق، من غير recursion ولا خطر على الـ stack
export function cheapestTable(quantity: number, boxes: readonly BoxType[], tick: Tick = noop): number | null {
  validate(boxes);
  const best = new Array<number>(Math.max(quantity, 0) + 1).fill(Infinity);
  best[0] = 0;
  for (let need = 1; need <= quantity; need++) {
    for (const box of boxes) {
      tick();
      best[need] = Math.min(best[need], box.cents + best[Math.max(0, need - box.units)]);
    }
  }
  return Number.isFinite(best[Math.max(quantity, 0)]) ? best[Math.max(quantity, 0)] : null;
}

// الخطوة 4: محتاج آخر maxUnits قيمة بس، فـ ring بدل الجدول كله
export function cheapestRing(quantity: number, boxes: readonly BoxType[], tick: Tick = noop): { cents: number | null; slots: number } {
  validate(boxes);
  const slots = Math.max(1, ...boxes.map((b) => b.units)) + 1;
  const ring = new Array<number>(slots).fill(Infinity);
  ring[0] = 0;
  for (let need = 1; need <= quantity; need++) {
    let best = Infinity;
    for (const box of boxes) {
      tick();
      const previous = need - box.units;
      best = Math.min(best, box.cents + (previous <= 0 ? 0 : ring[previous % slots]));
    }
    ring[need % slots] = best;
  }
  const answer = quantity <= 0 ? 0 : ring[quantity % slots];
  return { cents: Number.isFinite(answer) ? answer : null, slots };
}

type History = readonly string[];

// الخطوة 1: recursion، الأسوأ لما مفيش ولا عنصر مشترك
export function lcsRecursive(a: History, b: History, tick: Tick = noop): number {
  const solve = (i: number, j: number): number => {
    tick();
    if (i === a.length || j === b.length) return 0;
    if (a[i] === b[j]) return 1 + solve(i + 1, j + 1);
    return Math.max(solve(i + 1, j), solve(i, j + 1));
  };
  return solve(0, 0);
}

// الخطوة 2: memo بمفتاح رقمي مفيهوش تصادم
export function lcsMemo(a: History, b: History, tick: Tick = noop): number {
  const memo = new Map<number, number>();
  const solve = (i: number, j: number): number => {
    tick();
    if (i === a.length || j === b.length) return 0;
    const key = i * (b.length + 1) + j;
    const known = memo.get(key);
    if (known !== undefined) return known;
    const value = a[i] === b[j] ? 1 + solve(i + 1, j + 1) : Math.max(solve(i + 1, j), solve(i, j + 1));
    memo.set(key, value);
    return value;
  };
  return solve(0, 0);
}

// الخطوة 3: الجدول، وبيخليك ترجّع الـ sequence نفسها
export function lcsTable(a: History, b: History, tick: Tick = noop): string[] {
  const table = Array.from({ length: a.length + 1 }, () => new Array<number>(b.length + 1).fill(0));
  for (let i = a.length - 1; i >= 0; i--) {
    for (let j = b.length - 1; j >= 0; j--) {
      tick();
      table[i][j] = a[i] === b[j] ? 1 + table[i + 1][j + 1] : Math.max(table[i + 1][j], table[i][j + 1]);
    }
  }
  const sequence: string[] = [];
  for (let i = 0, j = 0; i < a.length && j < b.length; ) {
    if (a[i] === b[j]) { sequence.push(a[i]); i++; j++; }
    else if (table[i + 1][j] >= table[i][j + 1]) i++;
    else j++;
  }
  return sequence;
}

// الخطوة 4: صفين بس، بس كده مبقاش ينفع ترجّع الـ sequence
export function lcsTwoRows(a: History, b: History, tick: Tick = noop): number {
  const [outer, inner] = a.length >= b.length ? [a, b] : [b, a];
  let below = new Array<number>(inner.length + 1).fill(0);
  let current = new Array<number>(inner.length + 1).fill(0);
  for (let i = outer.length - 1; i >= 0; i--) {
    for (let j = inner.length - 1; j >= 0; j--) {
      tick();
      current[j] = outer[i] === inner[j] ? 1 + below[j + 1] : Math.max(below[j], current[j + 1]);
    }
    [below, current] = [current, below];
  }
  return below[0];
}

  3. Table: نفس الـ states من تحت لفوق. نفس الـ complexity، من غير recursion ومن غير خطر stack.

في الـ interview غالبًا الجدول هو آخر محطة. اذكر الـ space optimization واكتبها لو اتطلب منك.

Common mistakes · غلطات شائعة

❌ shift() as a queue

while (queue.length > 0) {
  const job = queue.shift()!;
  handle(job);
}
✅ A head index

  handle(queue[head]);
}

بالعامية

❌ shift() بتحرك كل العناصر مع كل مرة (على array كبيرة)، فالـ BFS بقى O(n²) وإنت مش واخد بالك. الرقم الحقيقي هنا: 80,000 عنصر أخدوا حوالي 5.0 ثانية بالـ shift و3 ms بالمؤشر (≈، جهاز عليه ضغط). ✅ المؤشر head بيفضل ماشي والـ array مكانها، O(1) لكل عنصر، وعلى BFS الـ queue array ممكن تبقى هي الناتج نفسه.

❌ Recursion on input you don't control 
// لو الشجرة عمقها 20,000 هتقع
function countLeaves(node: Category): number {
  if (node.children.length === 0) return 1;
  return node.children
    .map(countLeaves)
    .reduce((a, b) => a + b, 0);
}
✅ An explicit stack 
// مفيش حد غير الـ memory
function countLeaves(root: Category): number {
  let leaves = 0;
  const stack = [root];
  while (stack.length > 0) {
    const node = stack.pop()!;
    if (node.children.length === 0) leaves++;
    for (const child of node.children) stack.push(child);
  }
  return leaves;
}
بالعامية

❌ الـ recursion على data جاية من مستخدم عمقها مش تحت سيطرتك: في القياس فوق وقع بـ RangeError عند عمق 20,000. ✅ stack صريح في array على الـ heap بيستحمل مليون node. وفي الـ interview: اكتب اللي أوضح، وقول الحد بصوت عالي، واعرض البديل.

Solution · الحل 
export interface BoxType {
  units: number;
  cents: number;
}

export interface Plan {
  cents: number;
  boxes: Map<number, number>;
}

// الجدول بيخزن كمان أنهي صندوق اديك أحسن تكلفة، وبعدين بنمشي لورا
export function cheapestPlan(quantity: number, boxes: readonly BoxType[]): Plan | null {
  if (boxes.some((b) => b.units < 1)) throw new RangeError("a box must hold at least one unit");
  const best = new Array<number>(quantity + 1).fill(Infinity);
  const usedBox = new Array<number>(quantity + 1).fill(-1);
  best[0] = 0;
  for (let need = 1; need <= quantity; need++) {
    boxes.forEach((box, index) => {
      const cost = box.cents + best[Math.max(0, need - box.units)];
      if (cost < best[need]) {
        best[need] = cost;
        usedBox[need] = index;
      }
    });
  }
  if (!Number.isFinite(best[quantity])) return null;
  const counts = new Map<number, number>();
  for (let need = quantity; need > 0; ) {
    const box = boxes[usedBox[need]];
    counts.set(box.units, (counts.get(box.units) ?? 0) + 1);
    need = Math.max(0, need - box.units);
  }
  return { cents: best[quantity], boxes: counts };
}
الجدول التاني usedBox بيخزن أنهي صندوق اديك أحسن تكلفة، والـ loop اللي بيمشي لورا بينقص box.units لحد الصفر. الكود ده اتجرّب: tests بتتأكد إن الصناديق بتغطي الكمية وإن سعرها بيساوي ناتج cheapestTable.

Cheat sheet · الخلاصة

  • 25 minutes = understand 3, plan 5, code 12, test 5. The cut to 15–20 comes from templates and fewer rewrites; understanding stays at 3.
  • Log per-phase timestamps and read the median. "Too slow" isn't actionable; "code leaks 2 minutes" is.
  • Keep talking. A silent fast solve still scores badly.
  • Linked list: dummy head, gap pointers (same moves as two-pass), slow/fast for loops (more hops, O(1) memory).
  • Tree: inherit (low, high), not parent-only. Recursion overflowed near ≈9,500 frames here: say it, and offer an explicit stack.
  • Top K: min-heap of size k, O(n log k). Ask if a heap can be assumed; write the 30-line one in 7 minutes if not.
  • Trie vs sorted array with binary search: name both before picking.
  • Backtracking: choose, explore, unchoose. Sort then break to prune. Worst case is unchanged, and copy the array into the result.
  • Graphs: model nodes and edges first; mark on enqueue; head index instead of shift(); Kahn for cycle checks.
  • DP ladder: recursion → memo → table → space-optimized. Two rows can't return the sequence.
  • Clean the first time: score yourself against the 10-point checklist, 8 or more to pass.
